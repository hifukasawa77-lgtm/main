# NEON PINBALL

GitHub Pages の `pinball.html` で遊ぶ、宇宙基地を舞台にしたピンボール。480 × 690 の論理座標で盤面を描画し、ゲーム画面と音源はブラウザ内で生成する。

## 操作

| 動作 | キーボード | タッチ |
|---|---|---|
| 左右フリッパー | 矢印、A / D、Z / M | 左右ボタンを個別に押す |
| 球の発射 | Space または ↓ を押して離す | 発射ボタンを押して離す |
| 台を揺らす | X、Q / E で左右指定 | 揺らすボタン |
| 一時停止と再開 | P / Esc | 停止・再開ボタン |

フリッパーは上昇中にフリッパーの上面に当たる球を捉えると強く打ち返す。短時間に台を揺らしすぎると、2.2 秒間フリッパーが停止する。

## 得点と進行

- バンパーは 150 点、ターゲットは 300 点、スリングは 85 点。ターゲット4枚を点灯すると 1,500 点を得て消灯する。
- 4 秒以内に続けて当てるとコンボになり、3・5・7・10 ヒットで順に 2・3・5・10 倍。タイムアウトや全アクティブ球の落下で解除する。
- バンパー10回、ターゲット全点灯、5連続ヒットを達成すると、球を2個追加してマルチボールを解放する。前のミッション中に達成した条件も記録する。
- マルチボール解放後、24 秒間の軌道防衛ボーナスが始まる。期間中のヒット得点はさらに2倍。バンパーに6回当てるとボーナスを完了し、5,000 点とエクストラボールを得る。時間切れ後はアレイ全点灯で再挑戦できる。
- 残球は初期3球。マルチボール中は盤面上の全アクティブ球を失った時に1球消費する。得点に応じて CADET、PILOT、ACE、COMMANDER へ進む。
- デイリー条件は UTC の日付ごとに決定し、開始したランの途中では変えない。最高得点、当日の記録、音量・ミュート・BGM・演出設定はブラウザに保存する。旧版 GameKit の最高得点を引き継ぐ。

## 実装と検証

- `engine.mjs` は 300 Hz 固定刻みでボールとフリッパーを更新し、フリッパー接触点の速度を含めて反発を解く。
- `render.mjs` は Canvas の静的背景を再利用し、画素密度と演出数を制限する。フレーム間隔に応じて粒子や残像を減らす。OS の視覚効果設定も初期値に反映する。
- `audio.mjs` は Web Audio でオリジナルの効果音と BGM を合成する。
- 広告用の領域は筐体と操作から離れたページ下部に作り、初期状態では非表示にしている。
- 単体テストは `node scripts/test-pinball.mjs`。ブラウザテストは Playwright と Chromium を用意し、`node scripts/test-pinball-browser.mjs` を実行する。
- システム Chromium の指定は `CHROMIUM_EXECUTABLE`、旧版 HTML の比較撮影は `PINBALL_BEFORE`、撮影先は `PINBALL_OUTPUT`、連続稼働時間は `PINBALL_SOAK_SECONDS` を使う。
