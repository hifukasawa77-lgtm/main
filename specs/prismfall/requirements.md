# 要件定義書 — プリズムフォール (PrismFall)

バージョン: 1.0.0
作成日: 2026-06-10
作成者: Plannerエージェント
承認者: PM 深澤

---

## 1. 背景・目的

### 1.1 背景

hideのポートフォリオサイト（GitHub Pages）に、技術力とビジュアルセンスをアピールできる新規Canvasゲームを追加する。深澤からの依頼は「ビジュアルが綺麗なテトリス風パズルゲーム」。GameKit（自作Canvasマイクロエンジン）を土台に、外部アセット（画像・音声ファイル）を一切使わずプロシージャル描画＋Web Audio APIのみで、既存ポートフォリオのGlassmorphism×シアン/パープルのトーンに調和した上品なビジュアルを実現する。

### 1.2 目的

- 標準的なテトリス（7種テトリミノ・回転・ライン消去・レベルアップ）のコアループを、誰もが知っている操作感で提供する
- 「ビジュアルが綺麗」を、ネオン過多のサイバーパンク演出ではなく、シアン/パープル基調の上品なグラデーション・グロー・パーティクル・Glassmorphism UIで実現する
- GameKitの各モジュール（Engine / Input / Sfx / Particles / UI / Save / MathX）をフル活用し、外部アセット（画像・音声ファイル）ゼロで完結させる
- 1ファイルのHTML（`gamekit/template.html`ベース）で実装可能な規模に収め、Code-Generatorが迷わず実装できる仕様にする

### 1.3 ゲーム名

| 言語 | 名称 |
|---|---|
| 英語 | PrismFall |
| 日本語 | プリズムフォール |
| サブタイトル | 落ちてくるブロックを揃えて消す、光と硝子のパズル / A glassmorphic block-clearing puzzle |

選定理由: 「プリズム」が光の屈折・グラデーションを連想させ、シアン/パープルのGlassmorphismテーマと自然に合致する。サイバーパンク的語感（ネオン・サイバー・グリッド等）を避けた。

### 1.4 対象ユーザー

| ユーザー区分 | 詳細 |
|---|---|
| プライマリ | ポートフォリオ訪問者（PC・タブレット・スマホでテトリス風ゲームを軽く遊ぶ層） |
| セカンダリ | 採用担当者・エンジニア（実装の品質・ビジュアル表現力を見る層） |

## 2. 機能要件（MoSCoW法）

### 2.1 Must（必須機能）

#### M-01: タイトルシーン
- ゲームタイトル「PRISMFALL / プリズムフォール」をGlassmorphismパネル上に表示
- ハイスコア表示（GameKit.Save経由でlocalStorageから取得）
- 操作方法の簡易説明（矢印/WASD・回転・ハードドロップ・ホールド）を日英併記
- Space / クリック / タップでプレイシーンへ遷移

#### M-02: コアゲームループ（標準テトリス仕様）
- 7種テトリミノ（I, O, T, S, Z, J, L）が出現し、フィールド上部から落下する
- フィールドサイズ: 10列 × 20行（標準）
- 7-bagランダム生成方式（7種を1セットでシャッフルし、偏りを防ぐ）
- 横移動（左右キー/ボタン）
- 回転（SRS: Super Rotation System準拠の簡易実装。回転時に壁蹴り（wall kick）を実装）
- ソフトドロップ（下キー押下中、落下速度を加速）
- ハードドロップ（瞬時に最下部まで落下し固定）
- ロック遅延（着地後、一定時間操作可能。0.5秒固定でよい）
- ライン消去判定（横一列が全て埋まったら消去し、上のブロックを下に詰める）
- 同時消去ボーナス（1列=Single, 2列=Double, 3列=Triple, 4列=Tetris）
- レベルアップ機構（一定ライン数消去ごとにレベルが上がり、落下速度が増加）
- スコア計算（標準テトリスのスコアテーブルに準拠）
- ゲームオーバー判定（新しいテトリミノの出現位置がブロックで埋まっている場合）

#### M-03: ホールド機能
- 現在のテトリミノを1つだけ保持領域に退避できる（Cキー/Shiftキー、またはホールドボタン）
- 1回のテトリミノ落下中に1回のみホールド可能（連続ホールド禁止）
- ホールド中のミノはホールドパネルにプレビュー表示

#### M-04: ネクスト表示
- 次に出現するテトリミノを最低3つプレビュー表示（7-bagの順序通り）

#### M-05: ゴーストピース
- 現在のテトリミノがハードドロップした場合の着地位置を半透明で表示

#### M-06: スコア・統計表示
- 現在スコア、レベル、消去ライン数合計を常時表示
- ゲームオーバー時にハイスコアを更新（GameKit.Save経由でlocalStorage保存）

#### M-07: ゲームオーバー処理
- ゲームオーバー時、結果（スコア・レベル・ライン数・ハイスコア更新の有無）をGlassmorphismパネルで表示
- Space / クリック / タップでタイトルシーンへ戻る

#### M-08: 操作方法（キーボード）
| 操作 | キー |
|---|---|
| 左移動 | ArrowLeft / KeyA |
| 右移動 | ArrowRight / KeyD |
| ソフトドロップ | ArrowDown / KeyS |
| ハードドロップ | Space |
| 回転（時計回り） | ArrowUp / KeyW / KeyX |
| 回転（反時計回り） | KeyZ |
| ホールド | KeyC / ShiftLeft |
| ポーズ | KeyP / Escape |

#### M-09: 操作方法（タッチ）
- 画面下部にタッチ操作用ボタン（Glassmorphismスタイル）を配置
- ボタン構成: ←／→（移動）、↻（回転）、↓（ソフトドロップ）、HOLD、HARD DROP
- 各ボタンの最小タップ領域は44px × 44px以上を確保

### 2.2 Should（推奨機能）

#### S-01: ライン消去エフェクト
- ライン消去時、消去された行に沿ってパーティクル（シアン/パープルのきらめき）が発生し、フェードアウトする
- 消去行が一瞬ハイライト（白〜シアンのフラッシュ）してから消える

#### S-02: コンボ表示
- 連続でライン消去した場合、「COMBO x2」等の表示をフィールド上にフェードイン/アウト演出付きで表示

#### S-03: レベルアップ演出
- レベルアップ時、画面全体に控えめな光の波紋（リング状グラデーション）エフェクトを表示
- 「LEVEL UP!」テキストをGlassmorphismパネルで一時表示

#### S-04: テトリミノのビジュアル強化
- 各テトリミノに固有のグラデーションカラー（シアン〜パープル系のバリエーション）を割り当てる
- ブロック1マスごとに、上部ハイライト（明るい色）+ 下部シャドウ（暗い色）でガラス・宝石風の立体感を演出
- ブロック外周にうっすらとしたグロー（box-shadow相当をCanvas shadowBlurで表現）を付与（過度にならない範囲）

#### S-05: 効果音（GameKit.Sfx使用）
- ピース移動音、回転音、設置音、ライン消去音（1〜4列で音階が変化）、ホールド音、レベルアップジングル、ゲームオーバージングル
- ミュートボタンをプレイ画面に設置（GameKit.Saveでミュート状態を保存）

#### S-06: ポーズ機能
- Pキー/Escapeキーまたはポーズボタンでゲームを一時停止
- ポーズ中はGlassmorphismオーバーレイで「PAUSED / 一時停止」を表示し、操作を受け付けない

### 2.3 Could（あれば良い機能）

#### C-01: バックグラウンドパーティクル演出
- フィールド外側の余白にGameKit.Particlesによるアンビエントパーティクルを配置し、奥行き感を演出

#### C-02: フィールド背景グリッドの微細演出
- フィールドのグリッド線をうっすらとしたシアン/パープルのグラデーションで描画し、Glassmorphismパネル風の質感にする

#### C-03: テトリミノ落下軌跡エフェクト
- ハードドロップ時、落下経路に沿って一瞬の光の軌跡（トレイル）を表示

### 2.4 Won't（今回は対象外）

- マルチプレイ・対戦モード
- オンラインランキング
- 外部画像・音声ファイルの使用（全てプロシージャル描画・Web Audio APIで完結）
- ゲームモード切り替え（マラソン以外のモード: スプリント・ウルトラ等）
- リプレイ機能・ゲーム記録の動画出力
- アカウント機能・ログイン

## 3. 非機能要件

### 3.1 パフォーマンス

| 項目 | 目標値 |
|---|---|
| Canvas アニメーション | 60fps（requestAnimationFrame、GameKit.Engineのループに準拠） |
| 入力遅延 | キー入力からブロック移動までの遅延を1フレーム以内に抑える |
| HTMLファイルサイズ | 1ファイル 200KB以内（プロシージャル生成のみのため軽量） |

### 3.2 互換性

| 対象 | バージョン |
|---|---|
| Chrome（デスクトップ/モバイル） | 100以上 |
| Firefox | 100以上 |
| Safari（iOS含む） | 15以上（`ctx.roundRect` 対応が前提。GameKit.UI.glassPanelが内部使用） |
| Canvas API / Web Audio API | 必須 |

### 3.3 セキュリティ

- innerHTML へのユーザー入力反映なし（本ゲームはユーザーテキスト入力を持たない）
- localStorage（GameKit.Save経由）はJSON.parseのtry-catchが組み込み済みのものを使用
- 外部ネットワーク通信・外部リソース読み込みは一切行わない（CDN・画像・音声ファイル含め完全ゼロ）

### 3.4 デザイン制約

- 黒背景 (`#05070d`) + シアン (`#22d3ee`) / パープル (`#a78bfa`) アクセントを基調とする
- Glassmorphismパネル（`GameKit.UI.glassPanel`）をUI要素全般に使用
- アニメーションパーティクル背景（`GameKit.Particles`）を使用
- UIラベルは日英併記（例: "SCORE / スコア"）
- **サイバーパンク的演出（ネオングロウ過多・SF都市風・走査線/グリッチ演出など）は禁止**。グローは控えめに留める

---

## 4. 制約条件

| 制約 | 内容 |
|---|---|
| 技術スタック | 素HTML / CSS / JavaScript / Canvas API + GameKit のみ |
| ライブラリ追加 | 不可（GameKit以外の外部ライブラリ・CDNは使用しない） |
| ファイル配置 | リポジトリ直下 `prismfall.html`（1ファイル完結） |
| 外部アセット | 画像・音声ファイルは一切使用しない（全てプロシージャル描画 + GameKit.Sfx） |
| Graphic-Designer / Music-Generator | **本案件では出番なし**（全アセットがプロシージャル生成のため） |
| 既存ファイルへの影響 | 既存ファイル（index.html等）への変更は行わない（新規ファイル追加のみ） |
