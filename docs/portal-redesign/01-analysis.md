### 見た目・導線
- 配色は**白地（#fffbf5）＋オレンジ**のライトテーマ。CLAUDE.md の「黒背景＋シアン/パープル」とも、今回の「ダークネイビー×ブルー/シアン」とも一致していない
- ヒーローの主ボタンは「Claudeで作ったもの（ツール）」で、**ゲームへの主導線が無い**
- ヒーローのプロフィールカードの統計が **「24 Games」と固定値**（実数57）。説明文の `#games-count` は自動計数で正しい → 表示の不整合
- ナビ13項目が横スクロール。**スマホでハンバーガーメニューが無く**、ヘッダーが2段になって画面を占有する
- ゲーム欄はジャンルの絞り込みボタンのみ。**検索・並べ替え・新着・おすすめの自動表示は無い**（「気分で選ぶ」表は手書き）
- ページトップへ戻るボタン無し

### データの整合
- 案内エージェントの `agent-data.js` GAMES（55件）とトップのカード（57件）がずれている
  - トップにあって GAMES に無い: `hexlan.html` `tetra_territory.html` `tri_territory.html` `notebook.html` `kotonoha.html`
  - GAMES にあってトップに無い: `catan.html` `blokus.html` `blokus_trigon.html`
- 公開日・更新日のデータはどこにも無い → **git の履歴（ファイルの追加日・最終更新日）を正本にする**（捏造しない）
- アクセスランキングの元データは**存在しない**（後述）→ 「人気」は実装しない。代わりに「おすすめ（運営者の選定）」と「新着（git履歴）」を出す

### アクセス解析の現状（重要）
- 外部の解析サービスは**未導入**（GA4・Cloudflare Web Analytics等なし）
- ダッシュボードの「サイト訪問数」カードは
  1. `api.countapi.xyz`（**2023年にサービス終了済み**）を叩いて失敗し、
  2. **このブラウザの localStorage の訪問回数**を「サイト訪問数」として表示している
  → 指示書の「localStorage だけを集計してサイト全体のアクセス数と誤認しない」に**反している**。表記の是正が必要
- Cloudflare Worker（`cloudflare-worker/`）は案内チャット用の `/stats`（質問傾向）を持つが、ページビューは数えていない

## 3. リスクと後回しにするもの

| リスク | 対処 |
|---|---|
| ダーク化で、`background:white` 直書き（main.css 21箇所）と Canvas グラフの色（app.js 内）が浮く | 上書きCSSで面の色をトークンに寄せ、スクリーンショットで全セクションを目視確認 |
| app.js（465KB）は巨大で、ダッシュボード群が密結合 | **app.js は原則触らない**。新機能は別ファイル `assets/js/portal.js` に置き、既存DOMを読むだけにする |
| 保存データ（`site-lang`・ダッシュボード配置・TODO・ゲームのセーブ）の破壊 | 新しいキーは `portal-` 接頭辞のみ。既存キーは読み書きしない（E2Eで前後比較） |
| CSPハッシュ（JSON-LDを変えると変わる） | `security-csp.mjs --write` で再生成 |
| セクション12本の順序変更 | **しない**（既存の外部リンク `#works` `#dashboard` 等のアンカーを維持） |

**後回し**（本作業ではやらない）: ダッシュボード群の作り直し、ブログの仕組み変更、各ゲームページ側のデザイン変更、解析サービスの本番導入（深澤のアカウント操作が要る）。
