# 商品化計画 — 月3万円をどう作るか

2026-10-09 作成。担当: Claude Code（深澤の依頼「法務的に違反しないアプリを商品化。目標 月3万円」）

## 結論（先に）

1. **第一弾は「推し活ログ Pro」**（¥980・買い切り・BOOTHで販売）。実装済み、販売開始に必要な人の作業は**30分ほど**（下の「深澤がやること」）
2. 無料版は**そのまま全部無料**。Pro は「推し活を**見せる・染める**」追加パック。
   無料版で作ったレポート画像には**アプリ名とURLが必ず入る**＝SNSに貼られるたびに広告になる（ここが売上エンジン）
3. 月3万円 ≒ **Pro 約33本/月（1日1本強）**。無料ユーザーの2%が買う想定で **月間利用者 約1,700人** が要る。
   **開始1か月目から3万円は期待しない**（下の「到達までの見立て」）。note有料記事との合算で3か月目に届かせる計画
4. 静的サイトで課金ゼロ・個人情報ゼロのまま売る。決済・配信はBOOTHに任せる（出品無料・売れたときだけ手数料）

## なぜ「推し活ログ」か — 全アプリの法務仕分け

108ページを「売ってよいか」で仕分けた。**売る＝お金を受け取る**ので、無料公開より基準を一段上げている。

| 判定 | アプリ | 理由 |
|---|---|---|
| 🔴 売らない | ファミコンエミュ（`nes-emulator`） | 任天堂の商標・ROMの権利。販売は論外 |
| 🔴 売らない | ファーレンクエスト（`zelda_like`） | 既に改称済みだが出自が他社IP。販売すると争点が「似ているか」から「利益を得たか」へ移る |
| 🔴 売らない | ウイルス検知（`security-toolkit`） | ブラウザ内で「駆除」はできない。有料で売ると景品表示法（優良誤認）の問題 |
| 🔴 売らない | 心拍数・サーモ（`heart-rate` / `thermography`） | 有料化すると医療機器（薬機法）と誤認されうる表示の管理が要る |
| 🔴 売らない | ロト6分析（`loto6`） | 「当たる」と受け取られる商品は景表法・消費者トラブルの火種 |
| 🔴 売らない | でんしゃずかん（`train-collection`） | 鉄道会社の商標・車両意匠 |
| 🟡 保留 | 戦国/三国志/幕末/太平/源平 | 史実は自由だが、肖像・地図など**画像の出自を1枚ずつ証明できない**ものがある。販売前に legal-checker で全数監査が要る |
| 🟡 保留 | テトラ陣地・HEXLAN・SEVEN COLLECT ほか既存ボードゲームの翻案 | ルール自体は著作権の対象外だが、原作の商標・トレードドレスとの距離を個別に詰める必要 |
| 🟢 売れる | **推し活ログ** | 完全オリジナル。素材は自作＋出自記録つき（`assets/oshikatsu/README.md`）。データは端末内のみ＝個人情報の取り扱いが発生しない |
| 🟢 売れる | レシートOCR家計簿・Typing Dojo・学習リソース・シンセEQ・GameKit | 第二弾以降の候補（下の「次の商品」） |

推し活ログを選んだ決め手は法務だけではない:

- **市場**: 推し活は「お金を使うこと自体が楽しい」市場で、記録・可視化・シェアへの支払い意欲が高い
- **拡散の型がある**: 「今月の推し活費」「年間まとめ」をSNSに貼る文化が既にある（Spotify Wrapped 型）
- **既に完成度が高い**: 149項目の機械検査つき。売るのに足りなかったのは「払う理由」だけだった

## 「今のままじゃ売れない」と判断した点と、直したこと

| 売れない理由 | 直したこと |
|---|---|
| 全機能が無料。**払う理由が無い** | Pro を新設。既存機能は一切削らない（削ると既存ユーザーの信頼を失う） |
| 推し活は「見せたい」のに、**見せる手段がテキストのコピーだけ** | **レポート画像**（1080×1350 投稿 / 1080×1920 ストーリー）。端末内で描画し、スマホは共有シートから直接SNSへ |
| 使っている人がいても**外から見えない**（口コミが生まれない） | 無料版の画像に**アプリ名とURLを固定で入れる**。Proで外せる＝自然な購入動機 |
| 有料機能を**買う前に見られない** | 無料のままProのデザイン・年間まとめを**「SAMPLE」透かし付きで試せる**（保存はできない） |
| 推しの色で染めたいという推し活特有の欲求に応えていない | **メンカラテーマ**。黄色・ミント等の淡い推し色でも、文字は自動でコントラスト比4.5以上へ補正（読めない画面を作らない） |

## セキュリティ（売るものは守る・買った人も守る）

- **ライセンスキーは ECDSA P-256 署名**。ページには公開鍵しか無いので、キーの偽造には秘密鍵が要る。
  秘密鍵は深澤のPCだけ（`~/.oshikatsu-pro/`、リポジトリ外・`.gitignore` でも二重に遮断）
- **確認は端末内だけ**（WebCrypto）。キーも記録も送信しない＝オフラインでも使える・サーバー不要・個人情報を集めない
- キーは**JSONバックアップに入れない**（バックアップを人に渡したときにキーが漏れない）
- 流出したキーは `revoke` で無効化できる。偽のキーに「無効化済み」と答えて存在を教えることはしない
- 推し名などの入力は**キャンバスに描くだけ**で DOM に入れない（XSS の経路が無い）
- **正直な限界**: ページのJSを書き換えればProは開けられる（静的サイトの宿命）。¥980の買い切りで、
  これ以上の防御（サーバー認証・端末縛り）は**買った人の不便のほうが大きい**ので採らない
- 検査: `node scripts/verify-oshikatsu.mjs`（Pro 36項目を含む185項目）。`--inject` で署名確認を外すと❌になることを確認済み

| 記録件数 | 最初の描画 | DOM完成 | 全再描画 | レポート画像を開く |
|---|---|---|---|---|
| 0件 | 0.28秒 | 0.40秒 | 22ms | — |
| 500件 | 0.27秒 | 0.55秒 | 66ms | — |

## 売り方（毎週やること）

1. **X / Instagram で「#推し活」タグ付きの画像投稿**（週3本）。素材は自分で作ったレポート画像そのもの
   — 文面案は `marketing/oshikatsu-pro_booth.md`
2. **既存のSNS自動投稿**（`scripts/post-social.js`・毎週水曜）の文面に推し活ログを足す（marketerエージェントの担当）
3. **note** で「推し活費を記録したら年間〇万円だった」系の記事（無料）→ アプリへ誘導
4. BOOTH の検索流入（「推し活」「家計簿」タグ）
5. 月1回、BOOTH の販売数とアプリの利用状況を見て、効かない施策を止める

## 深澤がやること（販売開始まで約30分）

1. **鍵を作る**（深澤のPCで1回だけ）
   ```bash
   node scripts/oshi-license.mjs init
   ```
   → `~/.oshikatsu-pro/private.jwk` ができる。**USBメモリ・パスワード管理ソフトへ控えを取る**（失うと新しいキーを出せない）
2. **BOOTH に出品**（`marketing/oshikatsu-pro_booth.md` の文面をコピー）。ダウンロード商品・¥980
   - 特定商取引法に基づく表記の扱いは BOOTH の出品者向け案内に従う（住所・電話番号の表示方法を出品前に確認）
3. **配布ファイルを作ってBOOTHへアップロード**
   ```bash
   node scripts/oshi-license.mjs issue --lot 2026-10 --booth
   ```
   → `~/.oshikatsu-pro/dist/oshikatsu-pro-license-2026-10.txt` をBOOTHのダウンロードファイルに設定
4. **販売URLを入れて公開**: `assets/js/oshi-pro.js` の `STORE_URL = ''` にBOOTHの商品URLを入れ、
   `oshikatsu.html` の `oshi-pro.js?v=1` を `?v=2` に上げてコミット（`sw.js` が古い版を返すのを防ぐ）
5. 毎月1日: `issue --lot <新しい年月> --booth` で配布ファイルを差し替える（漏れたときの被害をその月の分に限る）

### 確認しておくこと（法務・税務）

- **商標**: 「推し活ログ」で J-PlatPat（特許情報プラットフォーム）を検索し、同名の登録商標が無いかを出品前に確認
- **Canva AI 生成の初期キャラ**: Proの商品そのものではないが、有料ページの画面に写る。Canva の AI 生成物の商用利用条件を再確認
  （`assets/oshikatsu/README.md` に既に注記あり）
- **税**: 給与所得者の副業所得は年20万円を超えると確定申告が必要（月3万円なら年36万円で超える）。BOOTHの売上明細を保存しておく
- **返金**: デジタル商品のため「キーが動かない場合を除き返金不可」とBOOTHの説明文と配布ファイルに明記済み
