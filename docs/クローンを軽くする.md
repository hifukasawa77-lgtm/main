# クローンを軽くする（Cドライブが厳しいとき）

## 何が重いのか

2026-08-25 実測、`hifukasawa77-lgtm/main` を浅くクローンした状態:

| 内訳 | 大きさ |
|---|---|
| `.git`（浅いクローンでも） | 625 MB |
| 作業ツリー | 644 MB |
| **合計** | **1.3 GB** |

作業ツリーの内訳:

| フォルダ | 大きさ |
|---|---|
| `assets/portraits` | 167 MB |
| `assets/sengoku` | 153 MB |
| `assets/genpei` | 111 MB |
| `assets/black-fang` | 31 MB |
| `assets/bakumatsu` | 22 MB |
| `local_llm`（学習済みモデル同梱） | 40 MB |
| **assets 合計** | **587 MB** |
| assets 以外すべて | 57 MB |

つまり **9割がアセット**です。一度に触るのは1〜2ゲームぶんなので、全部を持つ必要はありません。

## 軽量クローンの作り方

```powershell
# スクリプトを使う場合（scripts/slim-clone.ps1）
.\scripts\slim-clone.ps1 -Destination D:\work\main
```

手で打つ場合:

```powershell
git clone --depth 1 --filter=blob:none --sparse https://github.com/hifukasawa77-lgtm/main.git
cd main
git sparse-checkout set scripts docs gamekit .claude
```

### 実測値

| 状態 | 大きさ |
|---|---|
| ふつうの clone（浅い） | 1.3 GB |
| 上記クローンの既定（ルートのHTML/JS/CSSのみ） | **18 MB** |
| + `scripts` `docs` `gamekit` `.claude` | **20 MB** |
| + `assets/bakumatsu` `assets/maps` | **74 MB** |

**1.2 GB 以上空きます。**

### 3つのオプションの意味

| オプション | 効果 |
|---|---|
| `--depth 1` | 過去の履歴を落とさない。**旧PNG（WebP化前）が履歴に残っている**ため効果が大きい |
| `--filter=blob:none` | ファイルの中身は、実際に取り出すぶんだけ後から取る |
| `--sparse` | 既定でルート直下のファイルしか展開しない |

## 作業するゲームだけ足す

```powershell
git sparse-checkout add assets/sengoku      # 戦国風雲記   153 MB
git sparse-checkout add assets/genpei       # 源平         111 MB
git sparse-checkout add assets/portraits    # 肖像         167 MB
git sparse-checkout add assets/bakumatsu    # 幕末風雲記    22 MB
git sparse-checkout add assets/sanguo       # 三国志        16 MB
git sparse-checkout add assets/zelda-like   # ファーレン    18 MB
```

終わったら外す（ディスクが戻ります）:

```powershell
git sparse-checkout set scripts docs gamekit .claude
```

確認・解除:

```powershell
git sparse-checkout list      # いま展開しているフォルダ
git sparse-checkout disable   # 全部展開する状態へ戻す
```

## 注意

- **アセットを展開していないゲームのページは、画像が出ません**（ファイルが手元に無いため）。
  そのゲームを触るときに `sparse-checkout add` してください
- `git push` は通常どおり使えます。展開していないファイルは触っていないので影響しません
- `--depth 1` なので `git log` は1件しか見えません。履歴を辿りたくなったら
  `git fetch --unshallow` で全履歴を取れます（そのぶん容量は増えます）
- GitHub Pages の公開内容には影響しません。手元の展開範囲を変えるだけです

## 根本的な削減（別途）

`assets/` の 587 MB のうち **384 MB が PNG（335ファイル）** です。
CLAUDE.md の方針は「アセットは原則WebP」で、2026-08-02 に一度 WebP 化していますが、
その後に追加されたぶんが PNG のまま戻っています。

| PNGの多い場所 | 大きさ | ファイル数 |
|---|---|---|
| `assets/portraits` | 166 MB | 64 |
| `assets/genpei/hex-battles/backgrounds` | 63 MB | 19 |
| `assets/sengoku/gpt/portraits` | 38 MB | 17 |
| `assets/genpei/hex-battles/tokens` | 24 MB | 10 |
| `assets/bakumatsu/actions` | 21 MB | 9 |
| `assets/genpei/ai-portraits` | 21 MB | 58 |

WebP q90 へ変換すれば大きく減らせますが、**解像度は変えないこと**、
`drawImage` の source-rect を画素値で直書きしている箇所を洗うことが必須です
（CLAUDE.md「画像アセットの方針」を参照）。手順:

```bash
python3 scripts/optimize-assets.py --dir assets/portraits --dry-run  # 変換量の確認
python3 scripts/optimize-assets.py --dir assets/portraits            # 変換＋参照書換
python3 scripts/fix-webp-refs.py                                     # 取りこぼした参照
node scripts/verify-game-assets.mjs                                  # 全ページで404検査（必須）
```
