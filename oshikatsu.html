                                📅 月予算の設定 Monthly budget

                                推しごとの予算は「推し」タブで設定できます。予算の80%を超えるとダッシュボードが黄色、超過すると赤で知らせます。

                                👁 表示 Display

                                💾 データ管理 Data

                                データはこの端末のブラウザ内（localStorage）にのみ保存されます。サーバーには送信されません。ブラウザのデータ消去や機種変更で消えるため、ときどきJSONを書き出してバックアップしてください。

                                ℹ️ このアプリについて About

                                「推し活ログ」は、推しごとの出費・参戦・予定をブラウザだけで管理できる無料ツールです。インストール・ログイン不要。
                                Vanilla JS / Canvas API のみで実装。データは端末内に保存されます。外部へ送るのは、リサーチ機能で「調べる」を押したときの推しの名前だけです（記録は送りません）。
                                URLの末尾に #events のように付けると、そのタブを直接開けます（ホーム画面に置くときに便利です）。
