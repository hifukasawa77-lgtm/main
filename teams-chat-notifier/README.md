# Teams Chat Notifier

Microsoft Teams Web で、**チェックボックスで選んだチャットだけ**、メンションが無くても
デスクトップ通知する Chrome / Edge 拡張機能。

「メンションされないと気づかない」「毎回チャットを開いて確認している」「全チャットを通知
対象にすると煩い」を解決するための、通知のホワイトリスト方式。

## Teams 標準機能との違い

Teams にもチャットごとのミュートはあるが、以下が足りない。

| | Teams 標準 | 本拡張 |
|---|---|---|
| 一括での対象選択 | 1件ずつ右クリック | チェックボックス一覧＋検索で一括選択 |
| メンション以外の通知 | 全部来るか、ミュートで全部来ないか | 選んだチャットだけ全メッセージ通知 |
| 静音時間帯 | なし（全体設定のみ） | 時間帯を指定（履歴には残る） |
| キーワード通知 | なし | 未選択チャットでも指定語を含めば通知 |

## 動作要件

- Chrome または Microsoft Edge（最新版）
- Teams **Web版**（`teams.microsoft.com` / `teams.live.com`）
  — デスクトップアプリは非対応（DOMを読めないため）
- Teams のタブを開いたままにしておくこと（タブを閉じると監視も止まる）

**APIキー・外部サービス・課金は一切不要。** 通信は行わず、すべてブラウザ内で完結する。

## インストール手順

1. Chrome / Edge で `chrome://extensions/` を開く
2. 右上の「デベロッパーモード」をオン
3. 「パッケージ化されていない拡張機能を読み込む」→ この `teams-chat-notifier/` フォルダを選択
4. ブラウザで Teams を開き、チャット画面を表示する
5. 拡張アイコンをクリック → チャット一覧が出るので、通知したいチャットにチェックを入れる

初回はチャット一覧の取得に数秒かかる。一覧が空の場合は Teams のチャット画面を開いた状態で
ポップアップを開き直すこと。

## 使い方

### チャットタブ
- チェックを入れたチャットが通知対象。上部の検索窓で絞り込める
- 右上のスイッチで監視全体の ON / OFF
- 紫のドットは未読を表す

### 設定タブ
- **静音時間帯**: 指定した時間帯は通知を出さない。開始 > 終了なら日をまたぐ帯として扱う
  （例: `19:00`〜`08:00`）。この間の新着も**履歴には残る**ので後から確認できる
- **キーワード監視**: チェックを入れていないチャットでも、指定語がチャット名・送信者名・
  本文のいずれかに含まれていれば通知する。1行に1語。大文字小文字は区別しない

### 履歴タブ
- 直近50件の通知。クリックすると Teams のタブが前面に出て該当チャットへ移動する
- 静音時間帯に抑制された通知には「静音中」、キーワード一致には「キーワード」タグが付く

## 仕組み

```
Teams Web の左ペイン（チャット一覧）
  → content.js が6秒ごと＋DOM変化時にスキャン
  → 各チャットの「最終メッセージのプレビュー文」を前回値と比較
  → 変化していたら新着とみなす
  → background.js が 選択チャット / キーワード / 静音時間帯 と突き合わせ
  → chrome.notifications でデスクトップ通知
```

新着判定に未読バッジではなく**プレビュー文の変化**を使っているのは、バッジのDOM構造より
プレビュー表示のほうが変わりにくいため。「あなた:」で始まる自分の発言では通知しない。

## 既知の制約

- **Teams 側のUI変更で壊れる可能性がある**。セレクタは `content.js` 冒頭の `SELECTORS` に
  外出ししてあり、候補が全滅した場合も会話リンク（`a[href*="/conversations/"]`）を辿る
  フォールバック経路で動く。それでも一覧が取れなくなったらポップアップに警告が出る
- 検知間隔は最大6秒（DOM変化を検知した場合は約0.7秒）
- Teams のタブを開いていない間は検知しない
- チャットの**本文全体ではなく一覧のプレビュー文**を見ているため、長文は途中までしか通知に
  載らない（クリックして Teams で全文を読む前提）

## 検査

```bash
NODE_PATH=/opt/node22/lib/node_modules node scripts/verify-teams-notifier.mjs
```

静的検査（manifest 参照ファイルの実在・innerHTML 不使用・外部通信の不在）、ロジック検査
（静音時間帯の日跨ぎ判定・キーワード一致）、Playwright による DOM 検査（名簿抽出・新着検知・
自分の発言の除外・セレクタ全滅時のフォールバック）、popup の描画と設定保存を検証する。
