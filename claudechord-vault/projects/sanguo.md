# プロジェクト: sanguo

## 概要

三国志・天下三分（`sanguo.html`／326行の単一HTML・Canvas APIのみ）へ5機能を追加する。
最優先は **シナリオの実データ化**（`startScenario()` が `CITIES` の勢力配置を書き換えず、
赤壁を選んでも190年配置で始まる既知の欠陥を解消し、既存のシナリオイラスト8枚を機能させる）。
併せて、兵糧による軍拡のジレンマ・計略による知力ルート・名乗りを上げての一騎打ちを実装し、
「兵を貯めて殴るだけ」の支配的戦略を崩す。

## メモ・意思決定ログ

- 2026-07-28 設計3点セット作成（planner）。ブランチ `claude/sangokushi-feature-proposals-j5ab1l`。
- 2026-07-28 **決定: シナリオ setup は「190年ベース＋差分」ではなく全20都市フル記述（タプル短縮記法）**。
  184と223は190年と17〜19都市が異なり差分の圧縮率が出ないうえ、差分は盤面の可読性と検証性を大きく損なうため。
- 2026-07-28 **決定: 単一HTML維持でも ES Modules 化でもなく「データのみ classic script で外部化」**。
  `dynamic-test` が `file://` でページを開くため module は CORS で読めない。既存IIFEのクロージャ構造も壊さない。
- 2026-07-28 **決定: 画面遷移を「勢力選択→シナリオ選択」から「シナリオ選択→ストーリー→勢力選択」へ反転**。
  勢力の存在可否は年代に従属するため、従属する側を後に選ばせる。`playable` が UI の唯一のソースになる。
- 2026-07-28 **決定: 追加勢力は4つ（黄巾賊・呂布軍・荊州軍・南蛮）に限定し、劉璋/張魯/荊南太守は `han`（漢室）へ集約**。
  勢力カードと外交画面の破綻を避けるための意図的な簡略化。
- 2026-07-28 **決定: 一騎打ちの勝敗は演出開始前に全て確定させ、描画は再生専用にする**。
  スキップ時の整合性が構造的に保証され、演出中の状態遷移バグが発生しない。
- 2026-07-28 **決定: 勝利条件をシナリオ別にパラメータ化**（一律60%を廃止）。
  208赤壁の魏は開始時点で10/20=50%を保持しており、一律60%では3都市奪取で即勝利してしまうため。
- 2026-07-28 Graphic-Designer / Music-Generator への発注は不要と判断（新規画像なし・SFXはWeb Audioプロシージャル）。

### 第2次拡張の意思決定（2026-08-03）

- **決定: 政務ポイントは単一ゲート `apGate(kind)` に集約する**。実行可否の `why` 生成は現在
  `policyBtnHtml` / `genRowHtml` / `cityPanel` / `openPlotOverlay` / `buildDiplo` の5箇所に散在しており、
  各所に AP 判定を書き足すと「押せるのに何も起きない」不整合を必ず生むため。
- **決定: 輸送するのは兵のみ（「増援」）とし、兵糧は運ばない**。プレイヤーの兵糧 `state.food` は国庫一括で、
  都市別の `c.food` は `tickEconomyAI` / `aiPolicyChoice` / `aiMarch` だけが使う AI 専用フィールドであるため。
- **決定: 増援は即時到着とする**。輸送中の部隊をマップに描く方式は描画・セーブ・AI の三方に影響が及ぶ。
  強さはコスト・1巡1回・上限150で抑える。
- **決定: AI の churn は原因を是正し、`DIFFICULTY` のつまみでは誤魔化さない**。実測した往復の主因は
  ①`aiMarch` が出撃元の武将を全員連れ去る ②占領直後の守備が薄いまま増援手段がない
  ③目標を毎巡選び直す、の3点で、いずれも難易度倍率では解消しない。
- **決定: `bApplyResult()`（戦闘結果の式）は触らない**。占領後の守備が薄い問題は、
  プレイヤーは「増援」、AI は `aiReinforce()` という能動的手段で解く。式を変えると
  士気・一騎打ち・計略の既存バランスに波及するため。
- **決定: 検査用に `window.__sanguoDebug` を1つだけ公開する**（読み取り専用）。
  `state` が IIFE に閉じていて外から計測できず、AI 収束の受入基準（14〜16）を機械検査できないため。
  「グローバルを増やさない」規約への意図的な例外としてコードにコメントを残す。
