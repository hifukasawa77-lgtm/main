# 基本構想 — 源平争乱記（仮題 / Genpei Souranki）

> プロジェクトハブ: [[genpei]] ／ 姉妹作: 戦国風雲記（`sengoku.html`）・三国志天下三分（`sanguo.html`）
> 本書は**構想フェーズ（第1版）**。深澤の方針確認を経て `genpei_要件定義.md` → `genpei_基本設計.md` へ展開する。

## 0. 一行要約

戦国風雲記の日本地図・エンジン資産をそのまま土台に、**「城を獲る」ではなく「名分（大義）を獲る」**歴史シミュレーションを作る。
治承・寿永の乱（1180–1185）を中心に、保元・平治から奥州合戦までを7シナリオで扱う。

## 1. 背景

### 1.1 なぜ源平か

戦国風雲記（`sengoku.html` / 17,651行）は日本地図・城164・武将データ・ヘックス攻城戦・武装勢力64まで作り込みが進んだ。
同じ地図の上で**まったく違う遊び**を成立させられる時代として、源平合戦は次の理由で最適である。

| 観点 | 内容 |
|---|---|
| 地図が使い回せる | 令制国の区割りは12世紀と16世紀でほぼ同一。`provinces.json`（65国）がそのまま流用できる |
| 遊びが被らない | 12世紀に「城」はほぼ存在しない。拠点・戦闘・勝利条件の設計が根本から変わるため、戦国のリスキンにならない |
| 物語が強い | 平家物語という完成された筋書きがある。シナリオ選択＝章立てとして自然に機能する |
| 未開拓 | Web上のCanvas製・源平題材の歴史SLGはほぼ存在しない。ポートフォリオの差別化になる |

### 1.2 12世紀の政治構造 — 戦国と何が違うか

ここが本作の設計の芯であり、**戦国風雲記のシステムをそのまま持ってきてはいけない理由**である。

| 論点 | 戦国期（16C） | 源平期（12C） |
|---|---|---|
| 支配の単位 | 城と城下町。城を落とせば領地が移る | **国衙（役所）と荘園（私領）**。土地の所有権は京の権門（摂関家・寺社・院）にあり、武士は「管理者」にすぎない |
| 軍事拠点 | 数百の城郭。石垣・堀・天守 | 城郭は臨時の柵と逆茂木のみ。武士の本拠は**館（たち）**という屋敷 |
| 動員の根拠 | 大名への従属。知行と主従契約 | **御恩と奉公**。所領を安堵・給与された見返りに参陣する。契約が切れれば去る |
| 戦の主役 | 足軽の槍衾・鉄砲隊による集団戦 | **騎射（うまゆみ）**。馬上から弓を射る個人技。名乗りを上げての一騎討ちが儀礼として機能する |
| 勝利の条件 | 領国を広げ、最終的に武力で天下統一 | **官位と院宣**。平氏は全国の知行国を握りながら滅び、頼朝は生涯一度も京で戦っていない |

> **設計上の結論**: 本作の中核資源は「兵力」でも「石高」でもなく **「名分」** である。

## 5. 中核システム

### 5.1 名分（めいぶん）— 本作の背骨

戦国風雲記の「石高・兵力」に相当する最重要資源。**軍事力ではなく政治的正統性**を数値化する。

- **名分の源**: 以仁王の令旨 / 院宣 / 宣旨 / 官位叙任 / 三種の神器の保持 / 帝・院の身柄
- **名分が高いと**: 中立武士団の勧誘コストが下がる。国衙が戦わずに開城する。寺社が中立を保つ
- **名分が低いと**: 味方の武士団が離脱する。荘園から兵糧が上がらない
- **朝敵認定**: 敵勢力が院に働きかけて成立させる状態異常。名分が急落し、味方武士団に毎ターン離反判定が入る
  - 史実の再現: 1183年に平氏が、1184年に義仲が、1185年に義経が朝敵となり、いずれも一年以内に滅んだ

> 平氏を選ぶと「開始時点で名分が最高だが、恩賞に配る土地がなく、じわじわ削れていく」という
> 史実そのままのプレッシャーが体験できる。これが本作の一番の売りになる。

### 5.2 御恩と奉公 — 「忠誠度」の置き換え

武士団は所属するのではなく **契約している**。

| 行動 | コスト | 効果 |
|---|---|---|
| **本領安堵** | 小（名分を消費） | 既存の所領を保証。奉公度の減衰を止める |
| **新恩給与** | 大（占領した所領が必要） | 奉公度を大きく上げる。子飼いの家人になる |
| **恩賞の踏み倒し** | 0 | 奉公度が下がり続け、いずれ離反または謀反 |

**恩賞債務メーター**: 勝利するほど「約束した恩賞」が積み上がる。
配る土地が足りなくなると、有力武士団を粛清するか（＝頼朝が上総広常を誅殺した理由）、離反を受け入れるかの選択を迫られる。

### 5.3 拠点 — 「城」の置き換え

| 種別 | 数の目安 | 機能 | 備考 |
|---|---|---|---|
| **国衙（こくが）** | 各国1 = 約65 | 徴税・徴兵の中枢。占領で国単位の収入が入る | 名分が高ければ**無血で開城**する（在庁官人が勝ち馬に乗る） |
| **荘園（しょうえん）** | 約40 | 兵糧の供給源 | 寺社領・摂関家領を接収すると名分ペナルティ。目先の兵糧と正統性のトレードオフ |
| **館・城郭（たち）** | 約25 | 防衛拠点。柵と逆茂木のみの簡易防御 | 戦国の攻城戦を軽量化して流用。天守も石垣もないので短期決戦になる |
| **湊（みなと）** | 約15 | 水軍の母港。渡海の起点 | 保持していないと海戦・渡海ができない |

計 **約145拠点**。戦国の城164とほぼ同規模なので、既存のマーカー描画・パネル資産がそのまま生きる。

### 5.4 合戦 — 騎射と名乗り

ヘックス戦（`BattleScene`）を流用しつつ、兵種と勝敗判定を12世紀仕様にする。

- **兵種**: 騎射武者 / 徒歩の郎党 / 弓兵 / 楯持 / 水手・梶取
- **名乗り**: 開戦時、武将が名乗りを上げて一騎討ちを申し込める。受ければ両軍が見守り、勝者の側に大幅な士気ボーナス。
  戦国風雲記の一騎打ち演出をそのまま転用できる（むしろ**この時代の方が史実に忠実**）
- **騎射の間合い**: 密着すると騎射が無効化され太刀勝負になる。距離管理が戦術の核
- **崩れ**: 中世の戦は殲滅戦ではない。損害率より**士気**で決着する。大将が討たれると即座に総崩れ

### 5.5 水軍・渡海・潮流

屋島・壇ノ浦を成立させるための専用システム。

- **渡海**: 湊を保持し、船数を確保しないと海を越えられない。悪天候・季節で失敗判定
- **潮流**: 海戦マップは**数ターンごとに潮の向きが反転**する。順潮の側が移動力と射程で有利。
  壇ノ浦は「午前は平氏優勢、午後に潮が変わって源氏が押し切った」という史実そのものをルールにできる
- **水軍の寝返り**: 阿波水軍・田口成良の離反が壇ノ浦を決めた。海戦中に発生しうる離反判定を実装する

### 5.6 飢饉・季節

- **ターン単位 = 1ヶ月**。本編シナリオは60〜120ターン
- **養和の飢饉（1181–1182）**: シナリオ1で必ず発生する強制イベント。全国の兵糧が枯渇し、西国ほど深刻（史実通り）。
  約2年間、大規模な軍事行動が事実上不可能になる。**待つことを強いる**設計は歴史SLGとして珍しく、印象に残る
- **冬の北陸・東国**: 積雪で移動力が落ちる。義仲の北陸道進撃が春から夏にかけて行われた理由

### 5.7 三種の神器と安徳天皇

平氏が保持したまま西国へ落ちる。

- 保持側は名分に恒常ボーナス
- 鎌倉方の勝利条件に「神器の奪還」が含まれる
- **壇ノ浦で宝剣は失われる**（史実）。奪還を完全達成することは史実ルートでは不可能で、
  頼朝が最後まで抱えた不満をゲームの結末に落とし込める

## 6. 勝利条件

「全国統一」を一律の目標にしない。**勢力ごとに違う勝ち方**を定義する。

| 勢力 | 勝利条件 | 敗北条件 |
|---|---|---|
| **平氏** | 反乱勢力の鎮圧＋安徳天皇の治世維持（＝名分を保ったまま存続） | 都落ち後に神器と帝を失う |
| **鎌倉源氏** | 東国支配権の公認 → 平氏討滅 → 守護・地頭の設置（＝武家政権の樹立） | 頼朝の死、または坂東武士団の総離反 |
| **木曽源氏** | 入京し征東大将軍に任じられ、朝敵にならずに一年持ちこたえる（**高難度**） | 朝敵認定後の孤立 |
| **甲斐源氏** | 東海道を確保し、鎌倉に併呑されず独立勢力として残る | 頼朝への従属 |
| **奥州藤原氏** | 平泉の独立を1189年まで維持する（**籠城型・耐久勝利**） | 奥州合戦での敗北 |

## 8. デザイン方針

CLAUDE.md のサイト方針（黒背景 ＋ シアン／パープル系アクセント、Glassmorphism、**サイバーパンク禁止**）を維持する。
そのうえで本作固有の色設計を追加する。

- **勢力色は紅白**。平氏＝赤旗、源氏＝白旗。これは「源平戦」「紅白」という語の由来そのもので、史実的にも正しい
- UI クロームのアクセント（シアン／パープル）はサイト共通のまま。勢力色はデータ側の値として扱い、UI 配色とは分離する
- 装飾のモチーフ: 巻物・和紙の質感・墨・金泥。**平家物語の写本**を意識した縦書き見出し
- UI は日英バイリンガル表記（例: 名分 / Legitimacy、御恩と奉公 / Fief and Service）

## 9. 技術方針・非機能

| 項目 | 方針 |
|---|---|
| 実装形態 | 単一 HTML（`genpei.html`）＋ `assets/genpei/`。フレームワーク不使用、ビルドツール不使用 |
| エンジン | GameKit（`gamekit/gamekit.js`）を土台にする |
| データ | 拠点は CSV（`kyoten_ichi.csv`）、人物・シナリオ・国は JSON（`assets/genpei/`） |
| セーブ | localStorage。`SAVE_VERSION` を持ち後方互換を検査 |
| 対応 | デスクトップ／タッチ両対応（戦国風雲記の `IS_TOUCH` 分岐を踏襲） |
| 容量 | 追加アセットは WebP q90。1ファイル1MB超はリリース前チェックで検出される |
| 検証 | 戦国風雲記に倣い `scripts/verify-genpei-boot.mjs`（起動→マップ→ターン終了で例外0件）を必須ゲートとして先に用意する |

> ⚠ **タイトル画面が出た＝起動成功ではない**。描画ループの例外は「背景だけ残ってUIが出ない」形で現れる。
> GameKit は update/draw の例外を捕捉して `engine.errors` に積むため、`pageerror` だけ見る検査は素通りする（CLAUDE.md 既知の罠）。
