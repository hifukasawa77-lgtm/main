# 2026-10-08

## サイト全体のセキュリティ強化
- 現状: 厳格CSP（ハッシュ固定）は5ページだけで、**107ページ中87ページはCSP自体が無かった**
- 全ページへ基礎線を導入（`scripts/security-baseline.mjs`。検査＋`--write`で補う＋`--inject`）:
  CSP `object-src 'none'; base-uri 'self'; form-action 'self'`（script-src は触らない＝onclick多用のゲームを壊さない）／
  `assets/js/frame-guard.js`／Referrer-Policy。既存CSPは値を変えず不足指令だけ追記
- **学び: 旧インラインのフレームバスター `if (self !== top) top.location = …` は効いていなかった**。
  Chrome は操作無しの別オリジン iframe からの最上位遷移を例外も出さずに止める。実ブラウザ検査
  （`scripts/verify-frame-guard.mjs`、127.0.0.1 と localhost で別オリジンを作る）で発覚。
  frame-guard は抜け出しを試みたうえで常に操作を全面で遮る
- Worker: `withHardening` で全応答（平文エラー含む）に nosniff / CSP / XFO / HSTS / Permissions-Policy
- `SECURITY.md` と `.well-known/security.txt` を新設（報告窓口は GitHub の非公開報告）
- `verify-service-worker.mjs` 検査#17がキャッシュ名 `v6` を直書きしていて、SWの版上げで偽の赤になった → sw.js から読む形に修正
- 学び（フレームバスター・SW検査の版直書き）は同日中に CLAUDE.md「全ページのセキュリティ基礎線」節へ昇格済み

## 攻撃の遮断・シスログ・通知（同日・深澤の追加依頼）
- `cloudflare-worker/security-monitor.js` に一本化: 攻撃パターン403 → 拒否をIP別に数えて15分遮断（Cache API）→ RFC 5424 シスログ → Slack通知（err以上・同種10分1通）
- `frame-guard.js` が枠埋め込み・CSP遮断（外部スクリプト/イベント属性）を `/security/report` へ通報。インライン`<script>`遮断は拡張機能の雑音なので送らない
- 学び: **シスログの構造化値は改行を潰さないと、攻撃者がURLに改行を入れて偽のログ行を作れる**（ログ注入）。検査で実際に流し込んで確認
- 学び: **403を全部通知すると、Originなしのボットだけで通知が埋まる**。通知は err 以上に絞り、遮断カウントは全拒否で行う
- 管理トークン比較が `!==`（時間差で桁ごとに当てられる）だったので既存の `secureEqual` に統一
- 学びは CLAUDE.md「攻撃の遮断・シスログ・深澤への通知」節へ同日昇格済み
