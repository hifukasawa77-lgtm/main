# 2026-09-14

深澤さんの依頼で、**ZERO-1 デスクトップ版**（`zero-1-local-ai`）を対象に自己改善ループ。
あわせて、ポートフォリオ側の7コミットをマージするPR #345 を作成。

## 学んだこと

### 手で更新する登録簿は、黙ってずれる
検査1080件は緑、ルールと数値のずれも無し。**ずれていたのは登録簿だけ**だった。
診断の `TRACKED_FEATURES` に8件しか登録が無く、直近の**9機能が丸ごと漏れていた**。
決まりは2か所に書いてあり、その注意書きを書いた本人が9回続けて忘れている。
→ [[registries-drift-silently]] ／ [[0038-registries-need-mechanical-guards]]（**昇格済み**）

### 登録漏れは完全に無症状
何も壊さない。検査は緑、画面も動く。壊れるのは「診断が答えられない」という、
**使う人が困ったその瞬間**だけ。だから文章では守れない。

### 故障注入が、検査自身の弱点を捕まえた
5件のうち1件がすり抜けた——**目印がコメントの中にあっても「在る」と認めていた**。
それだと画面に出ていないのに診断が「反映済み」と答える。
**嘘をつく診断は、診断が無いより悪い。**

### 縛らない判断も、判断のうち
README を機械検査で縛るのはやめた。目印はUIの文言で、README の言い回しとは別物。
無理に揃えると**誤検知の出る検査**になる。代わりに、登録漏れで鳴る検査の
失敗メッセージへ書いた——**ちょうどその瞬間に読まれる場所**に置くのが効く。

## 意思決定
- 9機能を登録（8→18）＋ `tests/tracked-features.test.mjs` 新設＋README追記
- ポートフォリオの7コミットは **PR #345** として出した（main へ直接入れず、深澤さん承認待ち）

### 広げた翌日、その検査自身が誤検知を出した
昨日 判定を広げた検査が、今日 `2026-09-12` を咎めた。中身は**ボットの自動更新1件だけ**。
「無視される警告は、あるだけ害」と書いた当の検査が、翌日に誤検知を出した。
除外は**作者がボットであること1点だけ**に切った（メッセージや変更先で広げない）。
実測: 直近14日の65コミット＝人61＋ボット4で、人は1件も落ちていない。
→ [[0037-warnings-that-get-ignored]] に追記（**昇格済み**）

### 手の監査は続かない。機械で見るものだけが残る
ADR-0038 に「残り」と書いた穴（ZERO-1 に横断lintが無い）を同日中に埋めた。
手で監査したらずれはゼロだったが、**その監査は毎回誰かが手でやらないと効かない**。
`tests/docs-references.test.mjs` として検査に組み込んだ。
**いちばん危ないのは「文書に書いた数値」**——ずれても何も壊れないので、
「2,000行まで」と読んだ人が2,500行書いて検査で初めて落ちる形になる。
→ [[0038-registries-need-mechanical-guards]] に追記（**昇格済み**）

### 4回差し戻された（同じ機能で）
拍手 → 声のまま会話について、深澤さんから**4回続けて**「まだ直っていない」が来た。
①ONにならない ②音声で応答しない／手で送信が要る ③顔が動かない ④途中で止まる。
**4回とも検査は全部緑**で、4回とも実機のブラウザで時間を追って測って初めて見えた。
1回なら見落とし、4回なら**直し方のほうが間違っている**。

原因はそれぞれ: 消した設定値に行き先を書かなかった／提供元が合図の名前を変えていた
（Beta→GA）＋私が読み上げを止めて会話の輪ごと止めた／realtime が口の開きを誰にも
渡していなかった／「作り終わり」を「鳴り終わり」として口を閉じていた。

### 繰り返した形を数えたら、機械化すべき場所がそのまま出た
壊れた場所ではなく**繰り返した形**を数えた。「実装の書き方を照合する検査」は
CLAUDE.md に禁止と書いてあるのに**1日で3回**書いた＝文章では守れていない。
→ [[count-what-repeated-not-what-broke]] ／ [[0039-four-rejections-mean-the-loop-is-wrong]]（**昇格済み**）

### 誤検知が消せない検査は、書かずに捨てた
「合図を見るのは1か所だけ」を書いたが、保存先のファイル名 `zero1.db` や診断まで
咎めてしまった。**捨てた。** 誤検知が残る検査は鳴るたびに無視され、やがて本物の赤も
見逃される（ADR-0037 と同じ判断を、今度は「書かない」側で適用した）。

### 決まりを作ったら、守る手段があるかまで確かめる
「ブラウザで時間を追って測る」と決めた直後に気づいた——**その手段が無かった**。
声のままの会話は繋ぐと課金され、ここからは提供元へ繋げない。毎回使い捨ての偽の中継を
書いていたのが、そもそもの原因だった。`npm run practice` として置いた（課金なし）。

**その道具自身が、このセッションで何度も見た形の罠を踏んだ**のが一番の収穫。
引数を1つ落として呼び、変換は例外を出さず空文字を返し、画面は枝ごと読み飛ばした。
「両方ONで合図も100件届いているのに音だけ鳴らない」。推測せず測ったから見つかった。
