# 2026-08-09

## グラフィックEQ＆シンセサイザー（synth-eq.html）を新規制作

- **依頼**: 深澤から「グラフィックイコライザーとシンセサイザーを作りたい」。
- **判断**: 2ページに分けず**1ページに統合**した。EQは音源が無いと意味が無く、シンセは
  出力段が無いと閉じない。シンセ →（ディレイ/リバーブ）→ **10バンドEQ** → アナライザ、
  という一本の信号経路にすると両方が互いの説明になる。音源は
  シンセ／音声ファイル／マイクの3系統から選べるようにした。
- **実装**: 減算合成シンセ（OSC2基＋サブ＋ノイズ／フィルター＋EG／ポリ・モノ＋グライド／
  アルペジエーター／デモ演奏）＋ 10バンドEQ（31Hz〜16kHz・両端シェルビング）＋
  対数軸のスペクトラムにEQカーブを重畳、WAV書き出し。
- **検査**: `scripts/verify-synth-eq.mjs`（28項目）を新設して全PASS。
  `scripts/gen-synth-eq-og.mjs` でOGP画像を実画面から生成（1200×630 / 85KB）。

### 学び（Web Audio は「例外を出さずに無音になる」ので、例外0件の検査は意味が薄い）

Canvas ゲームの「タイトルは出るがUIが出ない」と同じ構図が音にもある。ノードの未接続、
`setValueAtTime` の時刻ミス、gain が 0 のまま——どれも **pageerror も console.error も出ない**。
検査は必ず `analyser.getByteFrequencyData()` の**ピーク値**まで見る。今回はプリセット8種を
総当たりで発音させ、1つでも peak=0 なら落とすようにした。

さらに**ヘッドレスでは `--autoplay-policy=no-user-gesture-required` が必須**。無いと
AudioContext が `suspended` のままで全項目が無音になり、原因を実装側に誤診する。

### 学び（`setTargetAtTime` 直後に `AudioParam.value` を読むと"偽の不合格"が出る）

「フェーダー値がフィルターへ届く」が `[0]=0 [9]=0` で落ちた。実装のバグではなく、
`setTargetAtTime` は指数的に漸近するため**直後の `.value` はまだ 0** というだけだった。
時定数の10倍（0.02s ⇒ 250ms）待てば 99.99% 到達する。同じ理由で
**無音判定はリバーブのIR長（2.4秒）より長く待つ**必要がある（600ms では余韻が残って必ず落ちる）。

音のパラメータは「命令した瞬間に値が変わる」ものではない、と検査側が知っていないといけない。

### 学び（EQカーブの抜き取り位置は「バンド周波数の真上」ではなく平坦部）

`getFrequencyResponse` で +12dB を入れたローシェルフ(31.25Hz)を、対数軸5%地点（≒40Hz）で
測って 3.7dB しか出ず落ちた。シェルビングが設定値どおりになるのは**遮断周波数より外側の平坦部**。
20Hz / 20kHz で測ったら 10.0dB / -11.7dB で通った。**検査の期待値がフィルターの性質と
噛み合っているか**を、落ちたときに実装側だけ疑わないこと。

### 学び（アナライザの置き場所ひとつでマイクのハウリング問題が消える）

マイク入力は「聴くとハウる／切ると可視化できない」のジレンマがある。
**アナライザを出力ゲインより前段に置く**（eqOut → makeup → analyser → outGain → destination）
だけで、「スピーカーへ出力」を切ってもスペクトラムと録音は生きたままになる。
UIで謝るより信号経路で解く方が早い。

### 学び（関数は巻き上がるが `let` は巻き上がらない＝起動時に丸ごと落ちる）

`saveState()`（関数宣言）を UI 配線から呼び、参照先の `let saveTimer` をファイル後方に
置いていたため TDZ で `Cannot access 'saveTimer' before initialization` になり、
**ページが何も描画されない**状態になった。関数宣言だけ見て「順番は自由」と思い込むと踏む。
状態変数は最初に使う場所より前で宣言する。
