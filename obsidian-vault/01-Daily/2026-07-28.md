# 2026-07-28

## 戦国風雲記: 攻城戦で画面下側（攻め手）が表示しきれない
- **報告**: 攻城戦のスクリーンショットで画面下端が切れ、攻め手（寄手）の部隊が見えない。
- **原因**: コミット `0589f17`（2026-07-24「戦国シナリオ初期配置と独立勢力表示を改善」）でキャンバスを **2560x2080 → 2560x1440（16:9）** に変更した際、戦闘ヘックス盤の幾何 `HEX = {size:68, cols:17, rows:15, ox:300, oy:250}` が据え置かれた。`hexCenter` は `y = oy + size*1.5*row` なので row14 の中心が y=1678、下端 y≈1746 と **H=1440 を 306px 超過**。攻め手の布陣行は rows13-14（`_buildStacks` の `baseRow=HEX.rows-1`）＋大筒も row14 なので、**攻撃側の全部隊が描画対象外**になっていた。さらに下段アクション列（y=1236..1368）が残る rows10-11 を覆っていた。
- **修正**: `HEX_DESIGN = {w:2560, h:2080, size:68, ox:300, oy:250}` を「設計キャンバス」として明示し、実キャンバスへ **contain フィット**（`HEX_FIT = min(W/2560, H/2080) = 0.6923`）してヘックス幾何を導出。盤面は y=126..1208 に収まり、全15行＋ボタン列が共存する。
- 盤面に重ねる文字・耐久バー・炎エフェクトは設計値（size68基準）で調整済みなので `hexPx(v)=v*HEX_FIT` を掛けて一緒に縮めた。掛け忘れると駒より文字が大きくなり隣ヘックスへはみ出す。
- ユニットコマンド／攻城謀略の縦積みボタン列（最大10段）は `x:760` で盤面中央に重なっていたため、盤面右外（x=2076..2536）へ移設。移設先は明るい城グラフィックの上で、無効ボタンの塗り `rgba(255,255,255,0.035)` が読めなくなったので背後に暗幕 glassPanel を敷いた。

### 学び（アスペクト比の変更は"派生ジオメトリ"を置き去りにする）
キャンバスサイズは1箇所の定数だが、そこから導出される盤面・トレース済みレイアウト・UI配置は**別の場所に絶対値で焼き込まれている**。`W/H` を変えたら「W/H から導出されるべき値が定数で書かれていないか」を横串で洗う。特にヘックス盤のような固定グリッドは、画面外へ落ちても例外も警告も出ず、**静かにゲームプレイを壊す**（今回は攻撃側が丸ごと不可視のまま4日間気づかれなかった）。

### 学び（トレース済みレイアウトは"設計キャンバス"を正として保つ）
`CASTLE_HEX_LAYOUTS` / `FIELD_HEX_LAYOUTS` は 2560x2080 のキャンバスへ背景画像を cover 配置した状態でトレースしてある。実キャンバスを変えるとき、盤面を等倍で置き直すのではなく**設計キャンバスごと contain フィット**すれば「画像上のどこにどのヘックスが載るか」の対応が保たれる。今回は背景画像が全て 16:9(1672x941) で実キャンバスへの cover＝画像全体表示のため、この関係が厳密に成立した（山城の帯曲輪・海城の水面と枠が一致することを実描画で確認）。生成側 `scripts/trace-battlefield-hexes.mjs` にも「W/H/HEX は設計キャンバスであり sengoku.html の HEX_DESIGN と同値に保つ」旨を明記した。
