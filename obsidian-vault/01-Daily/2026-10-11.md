# 2026-10-11

## Worker デプロイが通らない件（PR #403 / #404）
- run #20: トークン登録後も「Ensure KV namespace」で停止。原因は `2>/dev/null` で wrangler のエラーを捨てていて不明だった
  → KV は任意（Worker は無くても動く）なので、失敗理由を表示して KV 無しで続行するよう変更（#403）
- run #21: 本当の原因が判明 — `Headers.set: "***\n***" is an invalid header value` ＝ **シークレットに改行が入っていた（2行貼り付け）**
  → 「Check secret」でトークンの改行・空白と ACCOUNT_ID の形（32桁16進）を事前検査し、日本語で貼り直しを案内（#404）
- 学び: **エラー出力を `2>/dev/null` で捨てる検査は、壊れた理由ごと消す**。失敗したら理由を出してから判断する
- 学び: **`grep` は行ごとに当てるので「正しい値＋余分な行」を素通しする**。秘密値の形の検査は bash `[[ =~ ^…$ ]]` で文字列全体を見る（Codexレビューで発覚）
