## 学んだこと
- 構造化データは「書いた＝正しい」ではない。**実装していない機能（サイト内検索）や画面に無いFAQを申告すると、例外もエラーも出ないまま検索エンジンに嘘をつく**。申告は実装と突き合わせて消す
- GitHub Pages のプロジェクトサイト（`/main/`）では `robots.txt` はドメイン直下でないため無効。sitemap は Search Console から送る
- `assets/js/app.js` と `sitemap.xml` は CRLF。Pythonの `open(...,'w')` で読み書きすると**全行が差分になる**（17,266行の差分で気づいた）。書き戻し後に `git diff --stat` で行数を必ず見る
- `main.css` は SW の cache-first 経路なので、CSSを足したら `?v=` を上げないと再訪者に届かない
