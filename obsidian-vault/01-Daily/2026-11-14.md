# 2026-11-14

## ZERO-1（別リポジトリ zero-1-local-ai）次期開発5課題の着手
作業環境に Ollama・GPU・Windows 実機が無いので、実モデル/実機の値は全部「未測定」のまま、PC で1コマンドで測れる評価器と、承認不要の改善を独立PRにした（#193 RAG・#194 HTML実践課題・ほか2本）。

- **番号が実在しても中身は資料に無いことがある**: RAG の出典確認が `[S番号]` の実在しか見ず、「上限は80件です [S1]」（資料は50件）を通していた。数字と URL に限って資料と突き合わせる（意味は見ない＝偽検知を出さない）
- **「表示された」は完成ではない**: HTML 課題は押す・入れる・読み直すで確かめる。script を抜いた「見た目だけ」が 0/5 になることで採点器の反証を取った
- **上限が作業を黙って不可能にしていた**: Operator の計画は手順の引数を一律2,000字で断っており、ToDo 程度の HTML（約2,000字）は計画で必ず落ちていた。見本の HTML を偽モデルに渡す通し評価で初めて露見
- **時間で打ち切っても裏の処理は止まらない**: 打ち切った後に確認が積み増され 7件/5件 になった。止める印が要る
- **公称 8GB の GPU は 8188MiB**: `/1024 < 8` で「8GB の GPU が 8GB に足りない」と言っていた（Python 側にもあった）
- **変更前に固定した題で数える**: 言い換え中心の独立問題で BM25 は上位3件 2/12。その題を見て同義語表を作ると評価が意味を失うので作らず、埋め込みを同じ題で測る口だけ作った
