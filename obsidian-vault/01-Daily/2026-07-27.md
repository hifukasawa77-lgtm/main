# 2026-07-27

## 戦国風雲記: 「ターン終了ボタン」が3回にわたって壊れた
同じ症状（右上「ターン終了」が効かない／「操作を完了できませんでした」）を**別々の原因で3回**修正した1日。

1. **入力処理**（`01ad5e6`）: 画面固定ボタンを「押下位置を覚えて離した位置で判定」していたため、高DPI・全画面・タッチ対応ブラウザで release が Canvas 外扱いになるとボタンが音も反応も無いまま失われていた。`justPressed` で即実行する形へ変更。
2. **欠損データ（対症療法）** PR #288（`eb1eeb1`）: 前日追加した1550年シナリオの木曽家が参照する洲が province 未定義のまま残り、居城の無い大名として生成されて例外。該当洲を追加し、`normalizeDiplomacyState` に未登録大名の既定値補完を足した。
3. **構造的原因** PR #289（`b6fade5`）: 2で直しきれず別大名・別武将で再発。真因は ①`_endTurn` が「収入計上→AI思考→ターン確定」を state 直書きで進むため途中例外で**収入だけ確定**（＝押すたび金銭だけ増える）②DATA（洲・武将・大名）とセーブの不整合が例外源③削除した城をCSV取込が DATA にだけ復活させ、その不整合を**自ら作り出していた**。`normalizeGameState()` の追加・最下層アクセサの欠損耐性化・`_endTurn` のスナップショット/ロールバック化・削除済み城の復活防止で解決。旧セーブ相当8ケース＋例外注入＋城編集fuzzをPlaywrightで検証。

- **戦闘下部UIの見切れ**（`2597b9b`）: `actionY = H-160` に高さ144pxのボタンを置き余白16pxしか無く、ブラウザ枠・セーフエリアで下辺が欠けていた。`actionBottom`/`actionH` を分離して算出する形へ。
- その他: 出陣兵站と援軍の拡張・城編集マーカーの追従・1550年城主と外交一覧の拡充・シナリオ導入画像の刷新。

- **学び（同じ症状を2回直したら1回目は対症療法）**: #288 は「木曽家1家の洲を足す」個別修正で、翌コミットで別大名でも再発した。欠損データ1件で直った時は、**その欠損が生まれる経路**（後から増えるマスタ・ユーザー編集・外部取込）を洗い出さないと必ず戻ってくる。
- **学び（"押すたびに悪化する"は非冪等な再試行のシグネチャ）**: 金銭だけ増え続ける挙動は、多段処理の途中で例外が出て前半の副作用だけ確定していることを示す。原因箇所の特定より先にトランザクション性を疑う方が速い。
- **学び（エラーメッセージに要旨が無いと再報告を招く）**: 「操作を完了できませんでした」だけのフラッシュは手がかりがゼロ。`err.message` の要旨を出すようにして初めて原因追跡が可能になった。
