## 提案1: 案内エージェント（チャットウィジェット）のゲームカード画像欠落を解消する

- **背景/根拠**: `assets/js/agent-data.js` の `GAMES`（全37本）を静的解析した結果、**20本（54%）に `thumb` が未設定**（例: hanafuda, othello, no-luck-poker, dots-and-boxes, conhex, indigo, carrom, mahjong-solitaire, sengoku, hyakki 等）。案内エージェントがこれらのゲームを紹介する際、カード画像が出せずエモジ表示のみに落ちている可能性が高い（`agent.js` のカード描画ロジック側のフォールバック挙動は要確認）。index.html本体は一部（hanafuda等）で独自CSS/画像を持っているため実害はゲームによって異なるが、チャットウィジェット経由の訴求力は明確に半分以下になっている。
- **内容**: thumb欠落20本について、既存のゲーム内アセット（タイトル画面・盤面スクリーンショット等）から適切な1枚をWebPで切り出し `thumb` に設定する。専用アセットが無いゲームは graphic-designerエージェントでの新規生成、またはプロシージャル生成を検討する。
- **期待効果**: 案内エージェント経由の紹介率・クリック率向上（現状は/statsが未計測のため感覚値）。ボードゲーム中心のカタログの視覚的な見劣りを解消。
- **工数感**: 中（20本 × アセット選定/生成 + agent-data.js編集 + agent-evolve系検査の再実行）
- **受け入れ条件**:
  - `node -e "require('./assets/js/agent-data.js').GAMES.filter(g=>!g.thumb).length === 0"` が0件
  - `node scripts/agent-evolve-check.mjs` が緑
  - 追加した画像がWebP方針・解像度不変・アルファ保持の既存規約に適合（asset-guardian相当チェック）

## 提案2: 主要ゲームページのOGP/meta（SEO）欠落を優先度順に是正する

- **背景/根拠**: `seo-audit.sh` の実測で **111ページ中92件（83%）** がOGP/metaのいずれかを欠落。SNSでシェアされた際にog:image等が出ないページが多数を占め、流入経路の損失になっている。全111ページを一括是正するのは工数が大きいため、まず「案内エージェントのGAMES掲載37本＋index.html主要導線」に絞って優先是正するのが現実的。
- **内容**: `seo-audit` スキルのOGPテンプレを使い、GAMES掲載37本を優先して og:title / og:description / og:image / twitter:card / meta description / canonical を展開する。OG画像が無いページは既存生成手順（synth-eq等に実績あり）を流用する。
- **期待効果**: SNS経由シェア時の見え方改善、検索エンジンでのスニペット表示改善。
- **工数感**: 中（37ページ分のテンプレ適用＋OG画像生成。全111ページ対応は別途「大」）
- **受け入れ条件**:
  - `bash .claude/skills/seo-audit/seo-audit.sh` で GAMES掲載37本の欠落が0件
  - 生成したOG画像がSNSプレビュー（Twitter Card Validator等）で正しく表示される

## 提案3: Canvasゲームのアクセシビリティ（aria-label/role・reduced-motion）対応

- **背景/根拠**: `a11y-audit.sh` の実測で、多数のCanvasゲームに「canvasにaria-label/role/aria-hiddenなし」および「reduced-motion未対応」の指摘が出ている（blackjack, blokus, catan, go, othello, sengoku 等、少なくとも十数本）。CLAUDE.mdのCanvasゲームa11y指針（キーボード必須・一時停止・コントラスト）に対し、aria属性とprefers-reduced-motion対応が体系的に漏れている状態。
- **内容**: 既存ゲームのcanvas要素へ `role="img"` + 動的 `aria-label`（または `aria-hidden="true"` ＋別途の状態読み上げ領域）を付与し、`prefers-reduced-motion` メディアクエリでパーティクル背景等の演出を軽減するCSS/JS分岐を横展開する。GameKit採用ゲームは `gamekit/gamekit.js` 側で共通対応できる可能性があり、個別対応より優先度が高い。
- **期待効果**: スクリーンリーダー利用者・光感受性のある利用者への配慮、a11y-auditの✗件数削減。
- **工数感**: 中〜大（GameKit側の共通対応が効くゲームは小、個別実装ゲームは中）
- **受け入れ条件**:
  - `bash .claude/skills/a11y-audit/a11y-audit.sh` で対象ゲームの✗件数が現状より明確に減少（全ゲーム0件を初回のゴールにはせず、GameKit採用ゲームからの段階対応を受け入れ条件とする）
