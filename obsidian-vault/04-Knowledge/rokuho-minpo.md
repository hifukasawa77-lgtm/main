# 民法の条文地図 — 利用規約は定型約款・損害は不法行為と債務不履行・時効は5年/3年・無体物は所有権の客体でない

2026-10-13 現行（令和8年法律第45号の段階施行中・1173条）。引き方: `node scripts/legal-lookup.mjs 民法 548条の2`。
**読んだ範囲**: 総則（1〜6・90〜130・136〜169）、債権（399〜466）、契約総則（521〜548の4）、贈与・売買・請負・委任の要所、不法行為（703〜724の2）。

## 1. 契約・利用規約（このサイトの規約・投稿・課金すべての土台）
- 【民法521条｜契約をするかどうかを自由に決定】【民法522条｜書面の作成その他の方式を具備することを要しない】 — 契約自由。**口約束でも成立**する。
- 【民法548条の2｜定型約款】: 不特定多数相手で内容が画一的な取引の約款は、①約款を契約内容とする合意、または②**あらかじめ契約内容とする旨を表示**していれば、
  個別条項も合意したとみなされる。ただし**相手方の利益を一方的に害する不当条項は合意しなかったものとみなす**（2項）。
  → 利用規約は「同意ボタン」か、少なくとも**サイト上の事前表示**を置く。**表示が無ければ組入れが否定される**。
- 【民法548条の3｜定型約款の内容の表示】: 相手から請求があれば遅滞なく内容を示す義務。拒否すると組入れ（548条の2）が使えない。
- 【民法548条の4｜定型約款の変更】: 規約の一方的変更は、①相手の一般の利益に適合、②契約目的に反せず変更が合理的、のいずれか。
  **効力発生時期を定め、インターネット等で周知**する義務。周知なしの変更は無効になりうる。
- 【民法529条｜懸賞広告】: 「◯◯した人に賞品」という広告は、**知らずに達成した人にも**支払義務が生じる。ゲーム内外の賞金・景品企画で効く（景品表示法・賭博罪の論点も別途確認）。
- 意思表示: 【民法95条｜錯誤】【民法96条｜詐欺又は強迫】【民法97条｜到達】 — 契約は到達主義。課金画面の誤操作は【電子消費者契約に関する民法の特例に関する法律3条】も確認。
- **未成年者**: 【民法4条｜十八歳】【民法5条｜取り消すことができる】 — 18歳未満の契約は法定代理人の同意が無ければ**取り消せる**。有料機能・課金を置くなら年齢確認と返金方針を決める。
- 【民法90条｜公序良俗】【民法1条｜権利の濫用】 — 不当な規約・権利行使はここで止まる。

## 2. 債務不履行と損害賠償（外注・請負・自分のサービス提供）
- 【民法415条｜債務不履行】【民法416条｜通常生ずべき損害】【民法418条｜過失相殺】【民法419条｜金銭債務】 — 損害は**通常損害＋予見すべき特別損害**。
- 【民法420条｜賠償額の予定】: 違約金は賠償額の予定と推定。規約の**責任制限・違約金**は、消費者相手なら消費者契約法8条以下で無効になりうる（→ 取引系の別ノート）。
- 解除: 【民法541条｜催告による解除】【民法542条｜催告によらない解除】【民法545条｜原状に復させる義務】。
- 売買・制作物の契約不適合: 【民法562条｜履行の追完】【民法563条｜代金の減額】【民法564条｜損害賠償の請求】【民法566条｜一年以内】 — **知った時から1年以内に通知**しないと権利を失う（種類・品質）。
- 請負（制作委託）: 【民法632条｜仕事を完成】【民法634条｜注文者が受ける利益】 — 完成を約束する契約。**準委任**（【民法656条｜法律行為でない事務の委託】【民法644条｜善良な管理者の注意】）は完成義務がなく注意義務。
  グラフィック・BGM・AI生成物の発注は、契約類型を書面で決める（著作権の帰属は別。【著作権法61条｜譲渡】【著作権法27条｜翻案】で特掲が要る）。
- 【民法651条｜解除】: 委任はいつでも解除できる（不利な時期は損害賠償）。

## 3. 不法行為 — 権利侵害の民事責任の本体（著作権・名誉・プライバシー・商標の民事請求の受け皿は特別法と並ぶ）
- 【民法709条｜故意又は過失】 — 「権利または**法律上保護される利益**」の侵害。特別法に当たらなくても人格的利益の侵害で成立する。
- 【民法710条｜財産以外の損害】 — **慰謝料**。【民法723条｜名誉を回復するのに適当な処分】 — 謝罪広告等。
- 【民法715条｜使用者等の責任】【民法716条｜注文者の責任】 — **外注先の侵害の責任**: 注文者は原則責任を負わないが、**注文・指図に過失があれば負う**。素材を「これそっくりに」と指示するのは危ない。
- 【民法719条｜共同不法行為者の責任】 — **教唆・幇助も共同行為者**。侵害物の拡散・リンク・転載が問題になる根拠。
- 【民法714条｜責任無能力者の監督義務者等の責任】【民法712条｜責任能力】 — 未成年者の行為。
- 【民法724条｜三年間】【民法724条の2｜五年間】【民法166条｜五年間】【民法167条｜二十年間】 — **時効**: 不法行為は損害及び加害者を知った時から**3年**（人身は5年）、行為から20年。
  債権は知った時から5年・行使できる時から10年。
- **時効の止め方**（警告書が来た・出したとき）: 【民法150条｜催告】は6か月の猶予、【民法151条｜協議を行う旨の合意】は書面で1年、【民法149条｜仮処分】は終了後6か月、【民法147条｜裁判上の請求】で更新。
  → 交渉している間に時効が進む。**書面の協議合意**や提訴で止める。
- 【民法703条｜不当利得】【民法704条｜悪意の受益者】 — 無断使用で得た利益の返還（著作権侵害の不当利得返還請求の根拠）。

## 4. 「物」と情報（AI素材・データ・アカウントの権利の考え方）
- 【民法85条｜有体物】 — **「物」は有体物**。データ・画像ファイル・コードそのものは所有権の客体にならない（保護は著作権法・不正競争防止法・契約）。
  生成AIの出力やデータの帰属は、民法の所有権では片付かず、**契約（利用規約）＋著作権法＋不競法**で組み立てる。
- 権利の主体: 【民法3条の2｜意思能力】【民法99条｜代理】【民法108条｜自己契約及び双方代理】 — AIエージェントが「契約した」場合の効果は本人に帰属するかを、代理の枠で見る（現状は**AIは法人格を持たず、操作する人・事業者の行為**）。
