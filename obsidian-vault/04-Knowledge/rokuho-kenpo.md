# 憲法の条文地図 — 私人間には直接及ばない。効くのは表現・通信の秘密・人格権・財産権・令状主義

2026-10-13 に e-Gov 法令API の現行条文（制定時から無改正・103条）を全条読んだ。引き方: `node scripts/legal-lookup.mjs 憲法 21`。
`【法令名 条｜語】` の引用は `verify-legal-knowledge.mjs` が実条文と照合する。

## 大原則（最初に押さえる）
- 憲法は国家を縛る規範。**私人（自分・プラットフォーム・利用者同士）には直接適用されない**。私人間では民法の一般条項
  （【民法1条｜信義】【民法90条｜公序良俗】）を通して**間接的に**効く。
  → 「表現の自由があるのでこの投稿は削除できないはず」は、プラットフォームの規約削除には通用しない（契約の話）。
- 【憲法98条｜最高法規】【憲法81条｜憲法に適合するかしない】 — 法令の合憲性は最高裁が終審で判断する。
- 【憲法12条｜濫用】【憲法13条｜公共の福祉】 — 自由は「公共の福祉」で制約される。**制約が許されるかは「目的の正当性と手段の相当性」で見る**。

## このプロジェクトで効く条文
| 場面 | 条文 | 使い方 |
|---|---|---|
| 他人の顔・氏名・住所・私生活（肖像・プライバシー・名誉） | 【憲法13条｜幸福追求】 | 幸福追求権が**人格権（名誉・プライバシー・肖像）**の根拠。民法709条710条の「保護される利益」に流れ込む |
| サイト・SNS・ゲーム内の言論 | 【憲法21条｜表現の自由】【憲法21条｜検閲】 | 表現は広く保護されるが、**名誉毀損・わいせつ・著作権侵害は制約される**。検閲禁止は国家の事前審査への歯止め |
| DM・アクセスログ・端末内データ | 【憲法21条｜通信の秘密】 | 具体化: 【電気通信事業法4条｜通信の秘密】。事業者がログを扱うときの出発点 |
| 著作権・商標権・ドメイン | 【憲法29条｜財産権】 | 知的財産も財産権。内容は法律（著作権法等）で定め、権利制限（引用・私的複製）は「公共の福祉」の具体化 |
| 営業・副業・収益化 | 【憲法22条｜職業選択】 | 営業の自由。ただし景表法・特商法・資金決済法等で規制される |
| 捜索差押え・警察からの連絡 | 【憲法35条｜令状】【憲法33条｜逮捕されない】【憲法38条｜自己に不利益な供述を強要】 | 強制処分は**令状主義**。任意の協力か強制かを区別する（→ [[rokuho-keiso]]） |
| 処罰されるか | 【憲法31条｜法律の定める手続】【憲法39条｜実行の時に適法】 | 罪刑法定主義・適正手続。**行為の時に適法だったものは遡って処罰されない**（法改正の施行日が重要） |
| 争いになったとき | 【憲法32条｜裁判を受ける権利】【憲法76条｜司法権】【憲法82条｜公開法廷】 | 裁判は公開が原則。記録・判決は公開されうる（実名が残る点を依頼者へ説明する） |
| 歴史・宗教・差別的表現の扱い | 【憲法14条｜法の下に平等】【憲法19条｜思想及び良心】【憲法20条｜信教の自由】 | 歴史ゲーム等で特定の属性への侮辱になっていないか。法的リスクというよりプラットフォーム規約・炎上リスク |

## 私人間効力・人格権まわりの判例（**記憶ベース。報告に使う前に裁判所サイトで原典確認**）
- 最大判昭和48年12月12日（三菱樹脂事件）: 憲法の自由権規定は私人間に直接適用されず、私法の一般条項を通じて間接的に適用される。
- 最大判昭和44年12月24日（京都府学連事件）: 承諾なく容貌・姿態を撮影されない自由（肖像の保護）。
- 最判平成24年2月2日（ピンク・レディー事件）: パブリシティ権は「専ら肖像等の顧客吸引力の利用を目的とする」場合に侵害となる。
- 最判平成15年9月12日（早稲田大学江沢民講演会名簿提出事件）: 氏名・住所・電話番号も、本人が望まない開示から守られるべきプライバシー情報。
- 最決平成29年1月31日（検索結果削除請求）: 公表されない法的利益が優越することが明らかな場合に削除を請求できる。
- 最大判昭和61年6月11日（北方ジャーナル事件）: 表現行為の事前差止めは原則許されず、厳格な要件の下で例外的にのみ許される。
- 最判平成14年9月24日（「石に泳ぐ魚」事件）: 実在人物をモデルにした小説でもプライバシー・名誉の侵害は成立し、出版差止めが認められうる。
- 最大判昭和44年6月25日（夕刊和歌山時事事件）: 真実の証明がなくても、真実と信ずるについて相当の理由があれば名誉毀損の故意がない。

## 実務での注意（顧問弁護士の目線）
1. **憲法論で押し切らない**。争点は民法709条・著作権法・個人情報保護法など個別法に落ちる。憲法は「保護法益の存在」と「制約の限界」を説明する根拠に使う。
2. 実在人物（現存）を扱うゲーム・コンテンツは、**13条由来の人格権＋パブリシティ権**の両面で見る（歴史上の人物は別。死者の名誉は【刑法230条｜死者の名誉】の限定的保護）。
3. 通信の秘密は**「事業者の取扱中の通信」**が対象。個人運営のサイトでも、メッセージ機能を作れば電気通信事業法の届出・秘密保持が論点になりうる（要確認）。
4. 令状・任意の別が分からないまま「協力」や「提出」をしない。**弁護士へ連絡**してから（AIが代わりにはなれない）。
