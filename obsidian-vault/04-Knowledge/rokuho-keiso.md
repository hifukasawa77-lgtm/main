# 刑事訴訟法の条文地図 — 親告罪の告訴期間は6か月・公訴時効は罪の重さで決まる・強制処分は令状

2026-10-13 現行（令和8年法律第67号の段階施行中・724条）。引き方: `node scripts/legal-lookup.mjs 刑訴法 235`。
**読んだ範囲**: 捜査（189〜223）、告訴・告発（230〜245）、公訴（246〜262）、判決の入口（271・319・333〜336）。公判手続の細目・上訴・再審は構造のみ把握。

## 1. 捜査 — 任意と強制の区別（警察から連絡が来たとき最初に確認すること）
- 【刑事訴訟法197条｜強制の処分は、この法律に特別の定めのある場合でなければ】: **強制処分法定主義**。逮捕・捜索・差押えは法律と令状が要る。それ以外の取調べ・照会は**任意**。
- 【刑事訴訟法198条｜出頭を拒み】: 逮捕・勾留されていない被疑者は**出頭を拒める・いつでも退去できる**。取調べの前に**供述する必要がない旨**が告げられる。
- 【刑事訴訟法199条｜逮捕状】【刑事訴訟法210条｜急速を要し】【刑事訴訟法218条｜令状により】: 逮捕・差押え・捜索・検証は**裁判官の令状**（憲法33条35条）。
- **電磁的記録・サーバー**: 【刑事訴訟法218条｜電磁的記録提供命令】（2026-05-21施行）で、令状により**電磁的記録の提供**を命じられる。差し押さえるべき物が電子計算機のときは、
  接続している記録媒体（クラウド等）から複写して差し押さえる処分も（同条2項）。正当な理由なく違反すると【刑事訴訟法222条の2｜一年以下の拘禁刑】。
  → **サーバー・クラウドの管理者として、令状の範囲・提出先・期間を確認**する。通信を媒介する事業者には、通信履歴の電磁的記録を**30日（延長しても通じて60日）を超えない期間**消去しないよう求める保全要請がある（【刑事訴訟法197条｜三十日を超えない期間・消去しないよう】）。
- 【刑事訴訟法223条｜被疑者以外の者の出頭を求め】: 被疑者以外（参考人）にも任意の出頭要請ができる。**任意なので断れる**が、断る前に弁護士へ。

## 2. 告訴・告発 — 親告罪の鍵（このノートの最重要部分）
- 【刑事訴訟法230条｜犯罪により害を被つた者は、告訴をすることができる】【刑事訴訟法231条｜法定代理人】: 被害者・法定代理人・（死亡時）親族。【刑事訴訟法233条｜死者の名誉】: 死者の名誉毀損は親族・子孫が告訴。
- **【刑事訴訟法235条｜六箇月】: 親告罪の告訴は「犯人を知った日から6か月」で消える**。名誉毀損・侮辱・信書開封・秘密漏示などが対象。
  → 誹謗中傷の被害者側は**6か月以内に告訴**。加害者側（自分が書いた側）にとっては、**6か月の経過で刑事リスクが消える**が民事（3年）は残る（民法724条）。
- 【刑事訴訟法237条｜公訴の提起があるまでこれを取り消すことができる】: 告訴は起訴まで取り消せるが、**取消後は再告訴できない**（2項）。示談で取り消す実務の根拠。
- 【刑事訴訟法238条｜共犯の一人又は数人に対してした告訴】: **告訴の主観的不可分** — 共犯の一人への告訴は他の共犯にも及ぶ（親告罪）。
- 【刑事訴訟法239条｜何人でも、犯罪があると思料するときは、告発をすることができる】: **非親告罪は誰でも告発できる**（第三者の通報）。
- 【刑事訴訟法241条｜書面又は口頭で検察官又は司法警察員】: 告訴の方式。警察の窓口で受理を拒まれたら、書面を整えて再度（弁護士経由が確実）。
- 著作権法違反等は**親告罪が原則**（著作権法123条）。ただし一部は非親告罪化されている（同条2項）。**著作権者が告訴しない限り起訴されない**が、民事（差止・損害賠償）は別に進む。

## 3. 公訴（起訴するか）
- 【刑事訴訟法247条｜公訴は、検察官がこれを行う】【刑事訴訟法248条｜訴追を必要としないとき】: **起訴独占主義・起訴便宜主義**。犯罪が成立しても**起訴猶予**になることが多い（初犯・被害回復・示談）。
- 【刑事訴訟法259条｜公訴を提起しない処分】【刑事訴訟法260条｜告訴人】【刑事訴訟法261条｜理由を告げ】: 不起訴の通知・理由告知（告訴人の請求）。
- **起訴状謄本が2か月以内に被告人に届かなければ起訴は遡って失効**【刑事訴訟法271条｜二箇月以内】。

## 4. 公訴時効（罪の重さで決まる）
- 【刑事訴訟法250条｜長期十五年未満の拘禁刑に当たる罪については七年】: 長期15年未満→7年／長期10年未満→5年／長期5年未満または罰金→3年／拘留・科料→1年。
- 名誉毀損・侮辱・わいせつ物頒布・不正指令電磁的記録作成 → **3年**。電子計算機損壊等業務妨害（長期5年）→ **5年**。著作権法違反（119条1項: 10年以下）→ **7年**。
- 起算は【刑事訴訟法253条｜犯罪行為が終つた時】。【刑事訴訟法255条｜国外にいる場合】は国外滞在中は進行が止まる。
- 起訴（公訴の提起）で時効が止まる【刑事訴訟法254条｜公訴の提起によつてその進行を停止し】。

## 5. 証拠・判決
- 【刑事訴訟法319条｜任意にされたものでない疑のある自白】: 強制・脅迫による自白は証拠にできない。自白だけでは有罪にならない。
- 【刑事訴訟法333条｜刑の言渡】【刑事訴訟法336条｜無罪の言渡】。**執行猶予は判決と同時**。
