# 幕末風雲記 — playable prototype

ブラウザだけで動作する戦略ゲームの実装基盤です。`index.html` を開いてください。

## 実装済み

- 全国戦略マップと地域情報
- 月次進行、歴史イベント、資金・朝廷支持・近代化・緊張度
- 軍制改革／朝廷工作／対外交渉
- 人物データと肖像アセットのID紐付け
- 野戦・攻城戦・海戦を切り替えられる戦役画面（`battle.html`）
- 提示人物を勢力別に管理する肖像アセット台帳（`roster.js`）

## 追加方法

`data.js` の `GAME_DATA.people` に人物を追加し、同じ `id` で `assets/portraits/<id>.png` を置くだけで人物カードに表示されます。人物数はデータベース化前提の構造なので、500〜600人へ拡張できます。

`roster.js` の `CHARACTER_ASSET_MANIFEST` は、今回提示された全人物を勢力・人物ID・肖像パスで固定した台帳です。現在64名は対応するGPT-image 2.0肖像を実装済みです。
