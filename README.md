# 幕末風雲記

1853年の黒船来航から1869年までを舞台にした、**戦国風雲記のゲーム感を幕末へ移した**ブラウザ用ターン制ストラテジーです。全国地図の拠点を選び、内政・交渉・出陣・侵攻で勢力圏を広げます。

## 遊び方

1. `index.html` をブラウザで開き、勢力を選びます。
2. 自勢力の拠点では内政・出陣を、他勢力の拠点では交渉・侵攻を行います。
3. 「月を進める」で時代を進め、兵力・近代化・威信・民心を保ちながら勢力圏を広げます。

## シナリオと選択勢力

「黒船来航」「安政の政局」「京の政変」「薩長同盟」「大政奉還」「戊辰戦争」を収録しています。開始年代により選べる勢力が変わり、薩摩・土佐・長州・佐賀・水戸・会津・桑名・庄内・長岡・徳川幕府・福井を選択できます。

Space キーでも月を進められます。「記録する」でブラウザ内にセーブします。

## 同梱内容

- `assets/` — 提供された人物画、戦役画、全国地図
- `data.js` — 地域・人物・史実イベントのゲームデータ
- `battle.html` — 野戦・攻城戦・海戦の独立戦役画面

外部サーバーやビルドは不要です。
