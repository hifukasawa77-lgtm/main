# 07 紛争対応 — 警告書・削除請求・発信者情報開示・告訴・時効・証拠保全

**時間が勝負**の領域。弁護士へ回す前に**AIができる整理**（事実・期限・証拠）と、**やってはいけないこと**を渡す。
手続の条文: 民訴・刑訴の地図は `obsidian-vault/04-Knowledge/rokuho-minso.md`・`rokuho-keiso.md`。

## 1. 他者から警告書・内容証明・削除要請・捜査機関の連絡が来たとき（**受ける側**）
**0〜24時間（初動）**
1. **証拠を保全**: 受領した書面・メール・SNSの通知の**原本・日時・送信元**。**問題とされたページ・アセットの現状**（URL・取得日時・スクリーンショット・ハッシュ）。
   **削除・改変の前に**記録する（【民事訴訟法234条｜証拠保全】の発想: 失われる前に確保）。
2. **請求内容を分解**: ①誰が（権利者の資格・代理人）②何の権利か（著作権・商標・名誉・プライバシー・規約）③どの行為か（URL・日付）④何を求めるか（削除・謝罪・賠償金額・期限）⑤根拠法令。
3. **やらない**: 感情的な返信／**内容を認める発言**／相手への反論の拡散（SNS）／**証拠の削除・書き換え**（証拠隠滅と評価されうる）／**無視**。
**〜数日（方針決定）**
4. **事実確認**: 本当に自分の行為か・素材の出自・権利関係。**出自記録**があれば強い（→ 01）。
5. **暫定対応**: 争いのある表示を**一時的に非公開**にする判断（**損害拡大の防止**。**責任の承認ではない**旨を回答に書く）。
6. **時効・期限**: 請求の期限・相手の時効（【民法724条｜三年間】）。**自分が反論・協議するなら**【民法151条｜協議を行う旨の合意】（書面で時効の完成猶予）。
7. **弁護士へ**（**RED／金額が大きい／相手が代理人弁護士／仮処分・訴状が来た**は必須）。
**無視した場合の現実**: **仮処分（差止）**【民事保全法23条｜仮処分命令の必要性】→ 訴訟。**答弁しないと争わない事実は自白とみなされる**【民事訴訟法159条｜自白の擬制】。

## 2. 捜査機関から連絡が来たとき
- **任意か強制かを確認**【刑事訴訟法197条｜強制の処分】【刑事訴訟法198条｜出頭を拒み】。令状があるか（【刑事訴訟法218条｜令状】）。
- **黙秘権・弁護人依頼権**（【憲法38条｜自己に不利益な供述を強要】【憲法34条｜弁護人に依頼する権利】）。**自分で応じる前に弁護士**。
- サーバー・クラウドの**提出・差押え**は令状の範囲・対象・期間を確認（電磁的記録提供命令【刑事訴訟法218条｜電磁的記録提供命令】）。**勝手に消さない**（証拠隠滅）。
- AIは弁護人の代わりにならない。**法テラス**等の窓口を案内する。

## 3. 自分が権利者・被害者になったとき（**請求する側**）
| ステップ | 内容 | 期限・注意 |
|---|---|---|
| 1 証拠保全 | URL・日時・取得者・スクリーンショット・（可能なら公証・タイムスタンプ）。**原本性の立証**【民事訴訟法228条｜真正に成立したものと推定】 | 削除される前。**ログ保存期間は短い** |
| 2 権利の整理 | 著作権者は誰か・侵害の態様・損害の根拠（114条の推定等） | **出自の記録**が要る |
| 3 プラットフォームへの通報 | DMCA通知・各サービスの権利侵害申告 | **虚偽の通報は不法行為・不競法**【不正競争防止法2条｜虚偽の事実を告知】 |
| 4 発信者情報開示 | 【特定電気通信による情報の流通によって発生する権利侵害等への対処に関する法律5条｜発信者情報の開示請求】→ 開示命令（非訟） | **権利侵害が明らか**であること。**ログ保存期間**に注意 |
| 5 警告書 | 請求の趣旨・根拠・期限・連絡先。**脅迫・強要に当たらない**文面【刑法222条｜脅迫】【刑法223条｜強要】 | 時効の完成猶予（催告）【民法150条｜催告】は6か月 |
| 6 仮処分・訴訟 | 差止・損害賠償。**管轄**（プログラムの著作権は東京・大阪地裁専属【民事訴訟法6条｜プログラムの著作物についての著作者の権利】） | 少額なら**少額訴訟**【民事訴訟法368条｜六十万円以下】 |
| 7 刑事告訴 | 親告罪の告訴期間**6か月**【刑事訴訟法235条｜六箇月】。**起訴まで取消可・取消後は再告訴不可**【刑事訴訟法237条｜公訴の提起があるまで】 | **民事と刑事は別の時計** |
- **提訴前の照会・証拠収集**【民事訴訟法132条の2｜訴えの提起前における照会】（予告通知から4か月）。

## 4. 時効・期限の早見（記憶に頼らず引く）
| 請求・手続 | 期限 | 根拠 |
|---|---|---|
| 不法行為の損害賠償（財産） | 損害及び加害者を知って**3年**／行為から20年 | 【民法724条｜三年間】 |
| 人身損害 | 5年 | 【民法724条の2｜五年間】 |
| 契約上の債権 | 知って**5年**／行使できる時から10年 | 【民法166条｜五年間】 |
| **親告罪の告訴** | **犯人を知った日から6か月** | 【刑事訴訟法235条｜六箇月】 |
| 公訴時効（長期5年未満・罰金） | 3年 | 【刑事訴訟法250条｜三年】 |
| 取消権（未成年・錯誤・詐欺） | 追認できる時から5年／行為から20年 | 【民法126条｜五年間】 |
| 契約不適合の通知 | 知った時から**1年以内** | 【民法566条｜一年以内】 |
- **施行予定の改正**（`AMENDMENTS.md`）で時効・手続が動いていないかを確認。

## 5. 示談・和解の型
- 和解条項: **対象行為・金額・支払期限・謝罪の有無・削除・再発防止・守秘・清算条項（「本件に関し他に債権債務が無い」）**。
- **訴え提起前の和解**【民事訴訟法275条｜訴え提起前の和解】は和解調書が**確定判決と同一の効力**。
- 刑事の示談: 被害者の**告訴の取消**（起訴前）。**取消後は再告訴できない**。

## 6. 報告書に必ず入れる3点
1. **今日・明日やること**（証拠保全・やらないこと）。
2. **期限**（相手の期限・時効・告訴期間）。
3. **弁護士へ回す事項と、持っていく資料のリスト**。
