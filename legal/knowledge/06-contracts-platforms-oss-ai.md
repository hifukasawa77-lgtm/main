# 06 契約・規約・OSS・AIモデル・プラットフォーム — 外注・ライセンス・ToS・準拠法

前提: **ToS（利用規約）は頻繁に変わる**。このノートに書いてあるのは**確認項目と判断の型**で、**個別の条項は検査時点の原文（WebFetch）で確認**してから引用する。
OSSライセンス・AIモデルライセンス・外部ホストの分類は **`legal/knowledge/data/*.json`** に台帳として持ち、**スキャナが突合**する。台帳に無いものは「不明→要確認」。

## 1. OSS・CDNライブラリ（リポジトリの全HTMLの `<script src>`・`import`・CSS）
- 確認項目: ①**ライセンス種別** ②**帰属表示・ライセンス文の保持** ③**コピーレフト（GPL/AGPL/LGPL）** ④**バージョン固定とSRI**（セキュリティ側は security エージェント）⑤**特許条項**（Apache-2.0）。
- 配布形態: **CDN読込**はライブラリ側のヘッダ表示が残る。**自前同梱・minify**ではライセンス文を残す。**ライセンス一覧ページ**（`credits`等）を持つと帰属表示の要件をまとめて満たせる。
- **AGPL/GPL** がサーバー側・配布物に混ざると**ソース提供義務**。ブラウザで実行されるJS（配布）に GPL が混ざれば、**サイト全体のソース提供義務**が論点になる。**混ぜない**。

## 2. AIモデル・生成AIツールのライセンス（ZERO-1 Mobile・案内エージェント・素材生成）
- **モデルは「オープンウェイト」≠OSS**。ライセンスごとに条件が違う（台帳 `ai-model-licenses.json` 参照）:
  - Apache-2.0 / MIT 系: 商用可・表示・NOTICE。
  - **Llama系**: Llama Community License（**「Built with Llama」の表示**・派生モデルの名称・**月間アクティブユーザー7億超は別途許諾**・利用規約違反用途の禁止）。
  - **Gemma系**: Gemma Terms of Use＋**Prohibited Use Policy**（**用途制限が下流に継承される**）。
  - **Qwen系**: サイズによりライセンスが**Apache-2.0／Qwen License／Qwen Research License**に分かれる（**研究用途限定のものがある**）。**モデルカードで個別に確認**。
- **ZERO-1 Mobile**: 重みは**利用者の端末へ Hugging Face から直接ダウンロード**（サイトは再配布しない）。**サイト運営者に直接の再配布義務は小さいが**、①**ライセンス・禁止用途の表示**②**モデルカードへのリンク**③**禁止用途に使わせない注意**を画面に出す。
  **選べるモデル一覧に載せる前に**、各モデルのライセンスと**商用・再配布条件**を台帳に記録する。
- 生成AIツール（画像・音声・文章）: **商用利用可否・出力の権利・禁止用途・学習利用・帰属表示**を**利用規約（検査日付き）**で確認し、素材フォルダの出自記録に残す（→ 01 の5）。

## 3. プラットフォーム・外部サービスの規約（ToSチェックの型）
各サービスで確認する**5項目**: ①**自動化・bot・自動投稿**の可否 ②**商用/収益化**の制限 ③**ユーザーデータの扱い**（学習利用・保存期間・国外移転）④**API利用条件**（キー管理・レート・再配布）⑤**コンテンツ削除・停止の権限**。
| サービス | 要点（要確認・原文で） |
|---|---|
| GitHub Pages | **営利サイト・SaaS・EC を主目的とする利用は想定外**（利用制限）。**容量1GB・月間帯域100GB（目安）**。DMCA通知で停止されうる。**収益化を始める前に再確認** |
| Cloudflare Workers | 無料枠の制限・禁止用途・ログの扱い。**Workerのログに個人情報が残らないか** |
| Google（Gemini API／Fonts／MediaPipe） | **無料枠は入力が製品改善に使われる**条件があるか確認。Fontsは**利用者のIPがGoogleへ送られる**（外部送信・EU域の議論）。MediaPipeモデルは**ライセンス確認** |
| X・Instagram・Bluesky・Reddit | **自動化ルール**（自動投稿の可否・頻度・表示）・API規約・**宣伝行為の制限（Reddit）**・**画像の権利表明**。自動投稿は**認証情報が無ければスキップ**する設計（`scripts/post-social.js`） |
| Hugging Face | モデルごとの規約・**ゲート付きモデル**は同意が要る |
| note | **有料記事の規約・手数料・特商法表示の代行**・外部サイトへの誘導制限 |
- 規約に反する運用は**アカウント停止**が最初に来る（刑事・民事以前に事業継続リスク）。

## 4. 外注・委託（デザイン・音楽・実装・AI生成の依頼）
- **契約類型**: 成果物の完成を約す**請負**【民法632条｜仕事を完成】か、**準委任**【民法656条｜法律行為でない事務の委託】か。**書面で類型を決める**（著作権・検収・責任が変わる）。
- **著作権条項**: 成果物の著作権の**譲渡**／利用許諾の範囲。**翻案権・二次的著作物の利用権（27・28条）を特掲しないと譲渡されなかったと推定**【著作権法61条｜著作権の譲渡】（2項）。
  **著作者人格権は譲渡できない**ので**不行使特約**【著作権法59条｜一身専属】。クレジット表記の有無。
- **AI利用の可否と開示**: 外注先が**生成AIを使うか**・使うなら**ツールと規約・出自記録**。**第三者の権利を侵害しない保証**と**侵害時の責任分担**。
- **取引適正化**: **フリーランス法**（個人への業務委託の**取引条件の書面等明示**【特定受託事業者に係る取引の適正化等に関する法律3条｜明示】、報酬の支払期日【特定受託事業者に係る取引の適正化等に関する法律4条｜報酬の支払期日】、ハラスメント対策等）。
  **業務委託事業者が従業員を使用しない個人でも明示義務は及ぶ**範囲がある（要確認）。**資本金区分のある発注**は取適法【製造委託等に係る中小受託事業者に対する代金の支払の遅延等の防止に関する法律2条｜定義】（旧下請法）。
- **検収・契約不適合**: 受領後**遅滞なく検査**し不適合は**直ちに通知**（商人間なら商法526条）。→ `obsidian-vault/04-Knowledge/rokuho-shoho.md`。

## 5. 準拠法・管轄（海外の相手・利用者）
- 準拠法【法の適用に関する通則法7条｜当事者による準拠法の選択】（契約は当事者の選択）／消費者契約の特例【法の適用に関する通則法11条｜消費者契約の特例】（消費者の常居所地の強行規定が適用される主張が可能）／不法行為【法の適用に関する通則法17条｜不法行為】（結果発生地）。
- 管轄【民事訴訟法3条の7｜管轄権に関する合意】。**利用規約に準拠法・管轄を書く**が、消費者契約では**制限**がある。

## 6. AI推進法・ガイドライン
- 【人工知能関連技術の研究開発及び活用の推進に関する法律3条｜基本理念】【人工知能関連技術の研究開発及び活用の推進に関する法律7条｜活用事業者】: **罰則の無い基本法**。透明性・適正性・安全性の**努力義務**として、**AI生成物の表示・限界の説明・誤情報対策**を実務に落とす。
- 総務省・経産省「AI事業者ガイドライン」（記憶ベース・要確認）。
