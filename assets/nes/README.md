# NES 3D試作

ブラウザー版RETRO 8-BIT ROOMの3Dプレーヤーです。

- 3DはiNES / mapper 0（NROM）/ PRG 32 KB以下 / CHR ROM 8 KBに対応。その他は2Dモードで使用します。
- JSNES 2.1.0のPPU描画から背景とスプライトを分離し、画素を立体へ押し出します。ドラッグで回転、ホイールでズームできます。
- 右下の2D原画からタイルを選択し、背景／スプライト・タイル・パレット別の厚みと奥行きを調整できます。
- 設定はROMのSHA-256ごとに端末内へ保存し、JSONで書出し／読込みできます。
- スーパーマリオブラザーズとスパルタンXは厚み・HUDの初期設定のみです。両タイトルの実ROM検証と、ゲーム固有の立体形状の調整は未完了です。3dSen形式には対応しません。
- ROMやBIOSは同梱しません。
- 3Dの音声は画面内の音声ONから開始。ステートは画面内の保存／読込から操作します。2Dのステートとは互換性がありません。
- 2Dのコア展開に必要なunsafe-evalはplayer.htmlだけで許可します。親ページと3DプレーヤーのCSPは厳格なままです。

2026-11-15、自作NROMでChrome上のFCEUmm / Nestopia / 3D起動、タイル調整、設定保存・復元を確認。13件のNode.jsテストが通過しています。市販ROM・実ゲームパッド・スマートフォン実機・音声の聴取は未確認です。
