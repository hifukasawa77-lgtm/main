# 源平争乱記 可動ヘックス戦アセット

## レイヤー構成

1. `backgrounds/`: 駒・移動矢印・選択色を含まない1536×1024の盤面背景。
2. `tokens/`: 透明背景の可動駒。地上駒は円形、船は参照図に合わせた船型ミニチュア。
3. `terrain-rules.json`: 地形種別ごとの侵入可否、移動コスト、特殊条件。
4. `manifest.json`: 背景と駒のファイル対応、推奨表示サイズ。

## 実装上の原則

背景画像の色や見た目から通行可否を自動判定しないでください。各ヘックスはゲームデータ側で `q`、`r`、`terrain` を持ち、`terrain-rules.json` を参照して移動を判定します。崖や壊れた橋など、隣接セル間だけを遮断する場合は `edgeBlocks` を設定します。

石橋山では、尾根道は通行可能、森林斜面は高コスト、谷底・岩壁・海は侵入不可とします。船駒は `naval: true` の地形にだけ配置できます。

駒画像は高解像度のまま保持しています。描画時は `manifest.json` の表示サイズを基準に、縦横比を維持してセル中央へ配置してください。
