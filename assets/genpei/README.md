# assets/genpei/ — 画像アセット出所記録

`genpei.html`（源平争乱記）用の画像アセットの生成元を記録する。
**Graphic-Designer エージェントの絶対要件**: 画像を1枚作るごとに、生成に使ったツール名・プロンプト（や生成パラメータ）・生成日をここに追記すること。
（2026-08-02の学び: `assets/sengoku/gpt/sengoku-japan-map-user-v1.webp` の生成元が未記録で法務チェックYELLOW判定を受けた再発防止）

## 生成方法（共通）

- **ツール**: Python 3 + Pillow (PIL) 12.3.0 によるプロシージャル生成スクリプト（`GameKit.Gen` 同様、A-1「プロシージャル生成」方針。text-to-image系の外部生成AI・APIキーは一切使用していない）
- **生成日**: 2026-08-06
- **作者**: Graphic-Designer エージェント（Claude Code、このセッション）
- **ライセンス**: 完全オリジナル制作物。権利者なし・自由利用可（本リポジトリ内での利用に制約なし）
- **手法**: グラデーション空、ジャギー稜線による森・山のシルエット合成、鎧兜・騎馬・軍船等のベクター的シルエット部品（顔の写実描写は一切なし。後ろ姿・遠景・シルエット中心）、松明/炎のグロー、雨・雪・波・霧のパーティクル、紙目ノイズ＋ビネットで絵巻風の質感に仕上げ。スクリプト本体: `assets/genpei/_gen/genpei_gen.py`（部品ライブラリ）+ `assets/genpei/_gen/scenes.py`（15シーンの構図定義）
- **形式**: 全て WebP, quality=90, 1600×900, RGB（アルファ不要のため背景画像として不透明で保存）
- **時代考証**: 12世紀後半・治承寿永の乱を対象。大鎧・烏帽子・直垂・水干・薙刀・太刀・騎射・和船・僧形のみを描き、天守閣・石垣・火縄銃・南蛮胴など戦国期（16世紀）の意匠は一切含めない
- **人物表現**: 実在人物の特定を避けるため、鎧兜のシルエット・後ろ姿・遠景中心の構図とし、顔の写実描写は行っていない

## 個別AI生成肖像（`assets/genpei/ai-portraits/*.png`）

`genpei.html` は `PORTRAIT_ROOT = 'assets/genpei/ai-portraits/'` から `<武将id>.png` を読み込み、
`GENERALS`（存命50＋前史8＝58件）の肖像として実装済み（`assets/genpei/portraits/*.webp`
という当初設計のアトラス方式は不使用となり2026-08-06に削除済み。詳細は `obsidian-vault/01-Daily/2026-08-20.md`）。

- **生成元**: GPT Image 2（深澤が2026-08-23に確認）。個別のプロンプトファイルは
  `hex-battles/generation-prompts.md` のような形では残っていないが、
  生成ツールは `gpt/` 配下の他アセット（`assets/sengoku/gpt/` 等）と同一系統
- 画像は384×384のRGBA PNGで、写実的な肖像画スタイル（絵巻調ではなくポートレート写真調）
- 実在するのは12世紀に没した歴史上人物のみで、肖像権・存命人格権の問題はない
- 2026-08-06時点の法務チェック（`claudechord-vault/deliverables/genpei_法務チェック.md`）は
  「肖像は`drawPortrait()`によるプロシージャル描画のみで画像アセットは0枚」という前提で
  GREEN判定していたが、その後ai-portraits方式へ切替済み。本セクションで前提を更新し、
  2026-08-23の法務チェック（`claude/legal-check-historical-titles-v8uep6`）でGREEN確認済み

## 再生成について

構図を調整する場合は `assets/genpei/_gen/scenes.py` の該当関数を編集し、
`python3 assets/genpei/_gen/scenes.py` で再生成できる（出力先は環境変数 `GENPEI_OUT` で指定。
既定はスクリプト内の `out/` — 本番運用時は `battles/` `events/` へ手動でコピーし直すこと）。
