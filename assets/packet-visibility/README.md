# Packet Visibility UI

Light mint, blue and lavender interface for `packet-visibility.html`.

- `network-illustration.webp`: original illustration generated using the image generation tool; optimized to 768 × 512 WebP. No brand marks.
- `ui.css`: light desktop dashboard and mobile cards, fixed primary action and four navigation views below 700 px; safe-area and reduced-motion support.
- `app-ui.js`: mobile view switching and proxy actions for existing measurement/export controls. Navigation does not initiate network requests. Desktop keeps all sections visible.

Measurement, scoring, data storage and exports remain in the page. Chart and exported image colors are adapted to the light theme. Measurement requests consume data; results are stored locally.
