Use case: stylized-concept
Asset type: ultra-clean high-resolution game strategy map background for a Sengoku-era Japan map, no UI overlay.
Primary request: Create a clean Japan terrain map for a strategy game with real-map proportions. Tohoku from Miyagi/Sendai to Aomori must be vertically long like an actual Japan map, not compressed. The map must stay smooth and clean when zoomed in.
Canvas/intended output: high-resolution 3:2 landscape composition for a 4608x3072 game map.
Scene/backdrop: deep blue ocean, smooth turquoise coastal shallows, no ocean line patterns.
Subject: Japan archipelago with Honshu, Shikoku, Kyushu, nearby islands, and southern Hokkaido. Accurate general coastline and elongated Tohoku.
Style/medium: smooth painted terrain relief for a historical strategy game, broad airbrushed land colors, soft hill shading, clean coastlines. Mountains should appear as large shaded masses, not as individual white ridge lines. Use low-frequency texture only.
Composition/framing: wide top-down/oblique map, Japan diagonal southwest to northeast, enough ocean margin, no UI overlay.
Quality requirement: no pixelated texture, no noisy texture, no over-sharpened edges, no rough enlargement look. Avoid tiny high-contrast details; use smooth high-resolution gradients and softly blended terrain.
Hard constraints: no visible lines or streaks anywhere on land. No white mountain ridges. No roads. No rivers drawn as lines. No railways. No contour lines. No borders. No dashed lines. No white/yellow paths. No vein-like networks. No scratches. No labels. No text. No symbols. No markers. No castle icons. No UI. No random inland ponds, especially none in Kanto. Lakes should be minimal and subtle only where geographically plausible.
Avoid: satellite photo ridge networks, road-like paths, river webs, bright thin strokes, spiderweb patterns, white streaks, yellow lines, excessive detail, random lakes, blur from low resolution, watermark.
Post-process: source image was smoothed into a 4608x3072 game-ready asset to reduce line/streak artifacts and enlargement roughness.
