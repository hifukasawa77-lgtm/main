## 竹・木の昇降

竹林・杉林・沼の面に、手前に描かれる登れる幹と樹上の足場を追加。幹の近くで↑（W）を押すとつかまり、↑↓で昇降、離すとその場で停止、←・→だけでその方向へ幹から離れて落下し、Space＋左右では飛び離れます。樹上から↓で再び降りられます。奥の背景画像そのものには判定はありません。幹の配置・高さは推定です。昇降は背面から幹につかまる専用4コマ画像を使用し、停止中はつかまった姿勢で保持します。動作検査は climbing-validation.json。

## 原作BGMへの置き換え

仮の合成曲を廃止し、日本版 NSF の音楽データを FFmpeg/libgme で再生・音声化した16曲へ置き換えました。通常面はラウンドごとの原作4曲、般若門・門の中ボス・通常ボス・クリア・エンディングも専用曲です。ゲームプレイ録音の切り貼りではないため効果音は含みません。音量・M消音・ポーズ停止に対応。参考動画と通常曲をスペクトル比較しました。一部の短い比較区間はジングル等の影響で一致の信頼度が低く、全ての楽曲切替タイミングを原作と照合済みとは扱いません。ループ境界は反復解析による推定で、僅かな余白が残る可能性があります。ブラウザーの実音出力は未検証です。

音楽データ出典：https://www.zophar.net/music/nintendo-nes-nsf/demon-sword-jp 。原作：1988 Taito、NSF抽出：Ugetab、曲名タグ：Picto（同梱プレイリストによる）。楽曲の権利は原権利者に帰属します。詳細：original-bgm-manifest.json、bgm-reference-comparison.json、music-validation.json。

## 効果音と術の入手場所

原作NSFの個別音声コマンドからジャンプ・刀・飛び道具・命中・被弾・取得・弾消しの音を音声化して動作へ組み込みました。音そのものは原作データですが、刀・被弾・取得・弾消しなど、一部の動作との対応は暫定です。完全な原作一致と扱わず sfx-manifest.json に確認状況を記載。効果音はBGMと別音量・別消音、最大8音、同一音の過剰連打を抑制。実音出力はブラウザー未確認。検査結果は sfx-validation.json。風神の術などの単発術は全13面の通常配置から除き、般若門内でのみ入手（訓練場は操作確認用の例外）。
