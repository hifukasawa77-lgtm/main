# 降魔七星剣

`koma_ken.html` をHTTPサーバーで開く。外部ライブラリ・ビルドは不要。
全13面、13体のボス、結界門、4分類のアイテム、コードで描いたドット絵を収録。

## 操作

- 矢印/WASD: 移動。下でしゃがむ。上/Spaceでジャンプ、門の近くでは上で入る。
- Z: 剣。通常の敵弾を消せる。斬撃・光線などは消せない。
- X: 道具を投げる。休止中は手引の開閉。
- Enter: 開始・休止・再開。C: 訓練場の武器切替。
- 休止画面は上下で単発アイテムを選び、Zで使用。末尾の「タイトルへ」には確認画面がある。
- 手引は左右で5分類、上下で項目を選ぶ。閲覧中は時間が進まない。
- タッチ操作とゲームパッドにも対応。タブ非表示・ウィンドウのフォーカス喪失で自動休止。

## 音

初期状態は無音。「音 / Sound」で効果音のみ、またはBGM＋効果音を選べる。
音量と音の設定はこのブラウザーに保存する。保存不可の場合はその場の設定で動作する。
剣・投擲・命中・被弾・取得・ミス・ボス撃破の効果音と、タイトル・通常面・ボス・結界門・クリア・エンディング・ゲームオーバーの旋律をWeb Audioで合成する。
外部の音声ファイルや通信は使わない。音源は同時24個を上限とし、再生終了時に解放する。
休止・画面離脱・無音への切替で停止。ブラウザーの再生制限により、保存済みの音設定でもキー入力またはタップ後に再生を開始する。
音声APIが使えない場合もゲームはプレイできる。

## 保存

冒険の各面の開始時点を、このブラウザーの保存領域に1件保存する。
「続きから」は、その面の入口から体力全回復で、開始時点の得点・残機・所持品を復元する。
途中で拾ったアイテムや敵の状態は復元しない。新しい冒険は上書きする。
訓練場は冒険の保存に影響しない。冒険のゲームオーバーと最終面クリアで保存を削除する。
保存領域が利用できない場合もプレイを続け、保存できない旨を表示する。

## 検証（2026-10-27）

```sh
node scripts/verify-koma-input.mjs
CHROMIUM_PATH=/usr/bin/chromium node scripts/verify-koma-ken.mjs
```

ブラウザー検証には開発依存のPlaywrightとChromiumが必要。
ブラウザー検証187項目合格、入力単体検証合格。
効果音とBGMの音声バッファ生成、無音時の出力0、音源解放、場面切替、音設定の保持、休止・画面離脱時の停止、音声API非対応時のフォールバックを検証。
320×568、390×844、844×390、568×320で画面と44px以上の操作ボタンが重ならず、横にはみ出さないことを検証。
ブラウザーへのタッチイベント送信で開始・同時押し・中断・手引の操作を確認。

全13面の個別走破・ボスAIと弱点・門・ミス後の復帰・保存再開に加え、最初の面からエンディングまで連続進行する検証を実施。
連続進行は被弾を無効にしたボットが移動・ジャンプし、各ボスの弱点が開くまで実際のAIを動かした後、支給した攻撃アイテムで倒す。
通常の被弾条件で人が全編クリアできる難易度を保証するものではない。

通常被弾・残機消費を有効にした検証ボットでも、全13面のそれぞれでボス部屋まで到達。
各面を残機3・体力6で開始し、その面までのボス撃破で成長する武器を装備する。途中で体力・残機・無敵時間を書き換えず、実際の配置のアイテムだけを取得する。
一続きの通常条件での全ボス撃破を示す検証ではない。墓地（R1-3）は3ミス、魔寺（R1-4）と飛天の塔（R2-4）は2ミスとなったため、人による難易度評価では重点的に確認する。
全13体のボスも、各戦を独立した通常条件で開始し、剣と投擲による撃破を確認。
戦闘開始時は体力6・残機3・その面までに成長する武器とし、ボス部屋の入口から開始する。
以降は入力だけで操作し、体力・無敵時間・位置・ボスの状態を書き換えず、回復や攻撃アイテムを支給しない。
ミス後は通常仕様どおりボスの残り体力を維持して再挑戦する。最初の鬼面の女、岩坊主、空の天狗は残機0での撃破となり、人による評価でも重点確認する。
ボス登場時と休止画面に、そのボスの弱点や回避の手掛かりを表示する。休止画面では日英表記で繰り返し確認できる。
縦向き・横向きの画面を画像で確認し、小型横長画面で精密ポインターと判定された際にも操作ボタンを表示するよう修正。
操作説明を開閉式にまとめ、Enterで説明を開く操作がゲーム開始として扱われないことも検証。

2026-10-27に、最初から通常の被弾・残機・所持品を引き継ぐボットも試行。
実配置のアイテムを1個使用してR1-1をクリアし、残機0でR1-2へ進んだ後、2個目のアイテムを使ったボス戦（ボス残り体力16）でゲームオーバーになった。
この試行は結界門の回復や報酬を利用せず、全編クリアの根拠にはしない。難易度はこの結果だけで変更しない。
入力確認では、更新フレームの間に押して離した短いタップが取りこぼされる問題を修正。
キャンセルされた操作は除外し、正規の短い操作だけを次の更新で1回処理する。
ポインター由来のclickを二重処理せず、画面ボタンのEnter・支援技術による操作にも対応する。
展開した確認版の実時間操作では、キーボードの短押しも同様に取りこぼされることを確認し、次の更新で1回処理するよう修正。

この検証で再現・修正した不具合:

- 休止画面の攻撃アイテムでボスを倒すと、クリア状態が通常プレイで上書きされて進行が止まる。疾風・雷鳴・連爆それぞれに回帰検証を追加。
- 致命傷後も同じフレームのアイテム取得が処理され、ゲームオーバー中に回復や1UPが適用される。終了状態へ移った時点で更新を打ち切る。

## 完成前に残る確認

- 通常の被弾条件での人による通しプレイ、難易度・操作感の評価と調整。
- スマートフォン実機のブラウザーでタッチ操作・画面回転・アプリ切替を確認。
- 実機スピーカー・イヤホンでの音量バランスと聴感を確認。

## 確認版の配布ファイル

```sh
python scripts/package-koma-ken.py /tmp/koma-ken-preview.zip
```

ゲーム本体、必要なJavaScript、入口ページ、実機確認手順、ファイルのSHA-256一覧を同梱する。
ZIPをすべて展開し、`index.html`から起動する。ファイルを直接開く場合、保存領域の扱いはブラウザーにより異なるため、保存再開の確認ではHTTPサーバーの利用を推奨する。
